Three steps

From your library to burn-in on the timeline.

01

Add your library

Add your Final Cut Pro library to the host app by dragging it in, with "+" or with "Detect from Final Cut Pro", then choose the timeline. The host reads the library files itself. Or open the workflow extension inside Final Cut Pro.

02

Pick fields in the host

Choose which metadata to show and where it sits. A position preview window with drag layout shows the placement.

03

Apply on an adjustment layer

Put the Malibu Burn effect on an adjustment layer in Final Cut Pro. The burn-in appears over the picture beneath it.

What's inside

What the current version (0.3.62, beta) actually does.

Fields

23 metadata fields

Source timecode, project timecode, clip name, source file, reel, scene and shot, speed, notes, angle, resolution, markers (name, note or both), role text, stabilization, position, resize/transform, source frame, a stacked-layers reel block, a stacked-layers slate block and your own custom text.

Nine anchor points

Every element sits on one of nine anchors, so timecode, clip name and reel each go exactly where you want them.

Stacked layers

Reel and slate blocks for stacked layers are available as metadata fields.

Frame counts

Source frames count from the file's first frame, starting at 0.

Position preview

A preview window with drag layout shows where each element sits.

Role picker

Pick Video, Audio and Caption roles.

Presets and tools

Preset import and export, Bulk Style, and Validate against FCPXML. A visible-picture aspect constraint keeps the layout inside the picture.

Plugin updates

A banner tells you when a new effect version is available. The host fetches and installs the effect itself: choose "Update Plugin…" in the app and enter your Mac password once.

Good to know

What you need, and what it does not do yet.

Requirements

  • macOS 14.0 or later, Final Cut Pro (Final Cut Pro only)
  • Two parts: the Malibu Burn host app and a Final Cut Pro effect, both installed by the PKG
  • Effect updates: "Update Plugin…" in the app, Mac password once
  • The effect sits on an adjustment layer
  • Trial: an email address is required at first launch

Limits and known issues

  • Camera name is not available, there is no reliable source for it
  • Known bug: Final Cut Pro render cache after a trim
  • Open bugs with Y position in a 2:1 timeline
  • 24p media in a 25p project, [V1] tags and a gap with a connected clip are tested in the core but not yet seen live in Final Cut Pro
  • Preview positions are an approximation, Final Cut Pro renders the real text layout
  • Resize, position, stabilization and speed show nothing at default values, an empty field is not an error
  • Source Frame only works for file clips, not for generators, titles or compounds
