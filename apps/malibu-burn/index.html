The Workflow

Add the title, see it live.

🎬

Add the FxPlug title

Drop the Malibu Burn title onto your timeline like any other FCP title.

📚

Host reads the library

The Malibu Burn Host reads your .fcpbundle SQLite files in read-only mode — no injection, no private APIs.

🔄

Metadata resolves live

Timecode, clip name, reel, and camera are looked up per-clip and passed to the title via XPC.

⏱️

Burned in, frame-accurate

The overlay tracks every cut and retime automatically — no manual re-syncing.

What's inside

Burn-in without touching your FCP install.

Standard, unmodified Final Cut Pro from the Mac App Store — no code injection, no dylib loading, no private APIs.

⏱️

Frame-accurate timecode

Source timecode burned in per clip, tracking every cut and retime automatically.

🎬

Clip name & reel

Overlay the clip's real name and reel straight from FCP's own metadata.

📷

Camera metadata

Show which camera shot a given clip, useful for multicam and dailies review.

🧩

Standard FCP only

No modified Final Cut Pro required — works with the version from the Mac App Store.

🔍

Read-only

Reads FCP's SQLite library files in immutable mode — never writes to your project.

⚡

Live, not exported

No FCPXML round-trip — the overlay updates as you edit.

Why Malibu Burn

Built for dailies and screener workflows.
