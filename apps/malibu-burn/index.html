Three steps

From installer to burn-in on the timeline.

01

Install both parts

The installer package puts the Malibu Burn host app and the Final Cut Pro effect on your Mac in one go.

02

Pick fields in the host

Choose which metadata to show and where it sits. The host reads your Final Cut Pro project through a snapshot file.

03

Apply on an adjustment layer

Put the Malibu Burn effect on an adjustment layer in Final Cut Pro. The burn-in appears over the picture beneath it.

What's inside

What the current version (0.3.62, beta) actually does.

Fields

Fifteen kinds of metadata

Source timecode, project timecode, clip name, source file, reel, scene and shot, speed, notes, angle, resolution, markers (name, note or both), role text, stabilization, position and your own custom text.

Nine anchor points

Every element sits on one of nine anchors, so timecode, clip name and reel each go exactly where you want them.

Stacked layers, one per line

Stacked video layers are listed one per line with [V1] tags and in stack order. A gap with a connected clip still renders a burn-in.

Frame counts

Source frames count from the file's first frame, starting at 0.

Mixed frame rates

24p media in a 25p project is conformed correctly.

Role picker

Video and audio roles are split, with sub-roles shown.

Presets

Bundled "Netflix Playout 1920x1080" and "Conform Playout 1920x1080" presets, plus preset import and export. A visible-picture aspect constraint keeps the layout inside the picture.

Plugin updates

A banner tells you when a new effect version is available, and the installer applies it. Plugin updates need admin or App Management rights.

Good to know

What you need, and what it does not do yet.

Requirements

  • macOS 14.0 or later, Final Cut Pro
  • Two parts: the Malibu Burn host app and a Final Cut Pro effect, both installed by the PKG
  • Effect updates need admin or App Management rights

Not there yet

  • Camera name is not available, there is no reliable source for it
  • Live update after a trim is not confirmed yet
  • Open bugs with Y position in a 2:1 timeline
  • The latest changes are not yet verified in every Final Cut Pro setup
