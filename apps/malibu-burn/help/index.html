Getting started

What MalibuBurn does

MalibuBurn burns clip metadata into the Final Cut Pro viewer and into your exports: source timecode, clip and file names, reel, scene and shot, markers, roles and more. It has two parts. The MalibuBurn Host app decides what is shown and where. The MalibuBurn effect inside Final Cut Pro draws it.

Before you start

You need macOS 14 or later, Final Cut Pro, and the MalibuBurn plugin installed with the MalibuBurn installer. The plugin provides the effect that you add in Final Cut Pro.

The first launch asks for your email address. It is required: the Host shows only this screen until you enter one. The address identifies your trial.

Start the trial

Enter your email address and click Start Trial. The button stays disabled until the address looks like an email address. A short guide opens afterwards; you can reopen it at any time with How MalibuBurn Works in the Help menu.

Add your library and pick a timeline

Drag your Final Cut Pro library (the .fcpbundle) into the MalibuBurn Host window. Then click the timeline you are working on in the sidebar. The guide on adding libraries lists the other ways to add a library and explains how the timeline is chosen automatically.

Choose what to show

Pick a preset in the preset list at the top of the main column, or build your own by adding elements with Add element…. Changes reach Final Cut Pro within a moment; there is nothing to export or save.

Add the effect in Final Cut Pro

In Final Cut Pro, connect an adjustment layer above your timeline and stretch it over the full length. Open the Effects browser, go to Studio Malibu and drop the MalibuBurn effect onto that adjustment layer.

Check the result

The burn-in follows the playhead in the viewer and in every export. If the viewer shows a status line instead of metadata, the line names what is missing; the troubleshooting page lists the common lines. The Diagnostics section in the settings has everything support needs.

Add a library and choose a timeline

Drag the library into the window

Drag a Final Cut Pro library (a .fcpbundle) onto the MalibuBurn Host window. Anything that is not a .fcpbundle is ignored without a message.

Use the plus button

Click the plus button at the top left of the window (tooltip Add Library...), or click Add Library... in the empty sidebar. In the file panel, select the .fcpbundle. To look inside a folder, double-click it; a single click on the bundle and the panel's Open button choose it.

Detect the open libraries

With Final Cut Pro running and the library open, click Detect from Final Cut Pro. The button is in the empty sidebar and, as a wand icon, in the top row. One new library is added directly. If several are open, a list titled Multiple libraries are open in Final Cut Pro offers each library and Add All.

The first time, macOS asks whether MalibuBurn Host may control Final Cut Pro. Allow it. Libraries that are already added are skipped. If nothing new is open, nothing happens.

Fix a failed detection

If detection fails, the reason appears under the button in the empty sidebar (in the top row it is the tooltip). When macOS blocks the permission, the message in the empty sidebar gains two actions: Open Automation Settings opens the Automation pane in System Settings, where MalibuBurn Host must be allowed to control Final Cut Pro. Copy Reset Command copies a Terminal command that resets the stuck permission; run it, make sure Final Cut Pro is open, then click Detect from Final Cut Pro again.

Choose the timeline

Once a library is read, its Events appear in the sidebar as collapsible cards. Click a timeline to make it active; it then shows burning in. Click the active timeline again to deselect it. Events that contain no project or compound clip are not listed.

When the MalibuBurn workflow extension is open in Final Cut Pro, the Host follows the sequence that is active there. A timeline you pick in the Host replaces the extension's earlier choice.

Switch between the compact and the full list

While a timeline is active, the sidebar shows a compact card with the sequence name, library and event. Click Show All Libraries to see the full list again and Hide Library List to go back to the card.

Remove a library

Hover over a library row in the full list and click the circled x. The library is only removed from MalibuBurn; the file is not touched. There is no confirmation.

Set the project start timecode

If the burn-in shows a timecode that does not fit your timeline, type the project's start timecode into Project start TC (optional) at the bottom of the sidebar; it is shown while a timeline is active. Use HH:MM:SS:FF, or HH:MM:SS;FF for drop frame. Clear the field to go back to the value Final Cut Pro reports. An invalid entry is ignored and the hint under the field says which value is used instead.

Build your layout

Add an element

Click Add element… below the preset list and choose a field. The element is added to the active preset and selected. If an element was copied before, Paste element is listed first.

Select, hide and remove elements

Each element is a chip. Click the check mark to show or hide it, click the name to select it for editing (click the only selected chip again to deselect it), and click the x to remove it. Shift-click adds to the selection. The Delete key removes the selected elements. There is no confirmation and no undo.

Copy an element

Right-click a chip and choose Copy. Then choose Paste from the chip menu or Paste element from Add element…. The pasted element is added at the end of the active preset, also across presets.

Change the field and the label

Select an element. In the Editor tile, choose another Field or type a Label. For most fields the label is a prefix in front of the value; with stacked layers it appears in a tag such as [label V1]. For Custom Text the label is the text itself.

Place an element

In the Editor tile, choose an Anchor in the 3×3 grid, then set X and Y with the sliders or by typing a number. For a left, right, top or bottom anchor the value is the distance from that edge of the visible picture (0 to 1). For a centre anchor it is the offset from the centre (−0.5 to 0.5). Changing the anchor keeps the element where it is on screen.

You can also drag the element in the Position Preview. It snaps to the frame's edges and centre and to other elements. After a drag, on each axis you moved the anchor becomes the nearest edge or centre and X and Y are updated to match. Hold Shift to lock to one axis (pressing Shift at the start of a drag also toggles the element in the selection) and Option to move without snapping.

Style the text and background

Under Text set Text size (12 to 72), Text color, Text opacity and Alignment. Alignment only matters for multi-line content. Under Background switch Show background and set Background color and Background opacity.

Restyle all elements at once

Open the Bulk Style tile with the header icons above the preset list. Set the text, background or anchor draft and click Apply to all. The text and background drafts overwrite every element of the preset immediately; duplicate the preset first to keep the old state. The anchor draft re-expresses the positions in the new anchor, so elements stay where they are on screen. New elements take size, colors, opacity, background and anchor from the draft, but not alignment.

Open the Position Preview in its own window

Click the icon at the top right of the preview to open Position Preview as a separate window. Selection is shared with the main window. The separate window has the preview with its toolbar (Grid, Snap, Crop); the Editor, Settings and Bulk Style tiles stay in the main window.

Show clip roles

Add a Role Text element

Click Add element… and choose Role Text. The element starts in Role Name mode. It shows nothing until at least one role is picked; the Editor says so with the message "None selected yet — this element won't show anything until you pick one below."

Pick the roles

Select the element and open its Roles list in the Editor tile. Roles are grouped under Video Roles, Audio Roles and Caption Roles. Tick every role that should trigger the element. A main role covers all of its sub-roles and the clips assigned to the main role itself; open its arrow only to pick individual sub-roles. All sub-roles ticks just the named sub-roles of that main role.

The list is filled from the libraries you have added. When no roles are available it says "No roles found — pick a library/timeline first."

Choose what the element shows

Set Show to one of three modes. Custom Text shows the Label while a clip with a picked role is active. Media Filename shows the active clip's name, which the app uses in place of a file name. Role Name shows the role's own name. In the last two modes the Label is a prefix when it is not empty.

Check roles after importing a preset

The role selection of a preset belongs to the project it was made for, so a preset you import or share may not match the roles of your project. Check the picked roles after importing a preset.

Manage presets

Choose a preset

Use the list at the top of the main column. MalibuBurn comes with built-in presets, among them Netflix QC Layout, Conform and Colorist. Built-in presets can be edited in place, but they cannot be renamed or deleted.

Make your own preset

Click the plus button next to the list. It duplicates the current preset under the name <name> Copy and opens the Settings tile so you can rename it. Click the pencil to rename a preset of your own later.

Export and import

In the Settings tile, open Preset actions and choose Export preset… to write the preset as a JSON file, or Import preset… to read one. An import always becomes a regular preset and is activated. If the name exists, " (Imported)" is appended; nothing is overwritten.

Reset or delete

For a built-in preset, Preset actions offers Reset to factory default…, which discards your changes after a confirmation. For your own presets it offers Delete preset, which acts immediately; the last remaining preset cannot be deleted.

Set the visible picture

Under Canvas, Visible picture sets the picture area that element positions refer to: Full Frame, 2.39:1, 2.35:1, 1.85:1, 4:3 or Custom. Changing it moves elements, because X and Y are fractions of that area. The Position Preview shows it as a slightly lighter rectangle. Custom takes a width and a height, for example 1920 and 1080; a comma or a dot works as the decimal separator. You can still place elements in the bars around it unless Keep inside visible picture is on, which is off by default; elements never leave the frame itself.

Changes save themselves

Presets are saved automatically on every change. There is no save button.

Validate a timeline against FCPXML

Export the timeline

In Final Cut Pro, export the same timeline you selected in MalibuBurn as FCPXML.

Run the check

Select the timeline in the sidebar and open the Validate tile with the header icons, or the expanded Validate Against FCPXML window. Drop the .fcpxml or .fcpxmld file onto the zone, or click Choose FCPXML.... Without a selected timeline the tile asks you to pick one in the sidebar first.

Read the result

The check compares the clip list that MalibuBurn resolved with the FCPXML. PASS means every compared clip matched on timeline position, duration and name (and, for plain clips, on the source start), with no dropped or extra entries. FAIL means there are differences. The tile shows PASS or FAIL, a summary line and two counts; the window lists the differences, grouped as clips only in the FCPXML, clips only in MalibuBurn's list, and field mismatches on matched clips, up to 200 rows per group.

Use the right timeline

If the FCPXML contains no timeline with the selected name, MalibuBurn compares a fallback timeline from the file, and the window warns that it is not the timeline selected here. The tile shows no such warning. Export the FCPXML for the selected timeline for a valid comparison.

Update the Final Cut Pro plugin

Know what updates what

The Host app checks for its own updates with Sparkle; Check for Updates… in the app menu checks on demand. The Final Cut Pro plugin is updated by the Host: when the installed plugin is older than the Host, a banner at the top of the window reports it and installs the matching plugin.

Restart Final Cut Pro afterwards

After the banner reports "Final Cut Pro plugin updated to build", restart Final Cut Pro. It keeps the old version loaded until then.

Enter your password when asked

If the plugin was installed by the installer, click Update Plugin… in the banner. macOS asks for your password once; later updates install by themselves.

Allow App Management

If the banner says macOS won't let MalibuBurn Host replace the plugin, click Open App Management Settings, turn the permission on for MalibuBurn Host, then relaunch the Host. If it is already on, use the full installer.

Install or repair with the installer

Download Installer or Download Full Installer downloads the current MalibuBurn installer in your browser; run it afterwards. Use it when the plugin is not installed at all or an automatic update failed.

Restore a missing effect

If the banner says the effect is missing from the Motion Templates folder, click Open MalibuBurn once to reinstall it, then restart Final Cut Pro.

Reference

Requirements

  • macOS 14 or later.
  • Final Cut Pro with the MalibuBurn plugin installed. The effect is called MalibuBurn and sits in the category Studio Malibu.

Window and tiles

  • The Host window opens at 1200 × 760 and cannot be made smaller than 840 × 640.
  • Editor — the selected element: Element, Position, Text and Background, plus one more section for some fields. Open by default.
  • Settings — the preset's own settings: Preset, Canvas, Stacked layers, Visibility. Open by default.
  • Bulk Style — text, background and anchor drafts with Apply to all. Closed by default.
  • Validate — compares the timeline with an exported FCPXML. Closed by default.
  • Tiles open and close with the icons in the header above the preset list. When the content area becomes narrower than 860 points, open tiles are closed; tiles you open while it is narrow float over the main column.

Menus and shortcuts

  • MalibuBurn Help (Help menu) — opens these help pages in the browser.
  • How MalibuBurn Works (Help menu) — reopens the guide.
  • Send Feedback… (Help menu, ⌘?) — opens the feedback dialog.
  • Check for Updates… (app menu, not in Mac App Store builds) — checks for a new Host version.
  • Buy MalibuBurn (app menu) — opens the purchase page; shown until a license is confirmed.
  • The menu bar icon — a popover with the status, the active timeline and the libraries (a click on a library opens the Host window), a small icon in the top row that opens MalibuBurn Host (its tooltip is Open MalibuBurn Host), and a footer with Settings (⌘,) and Quit (⌘Q).
  • Delete — removes the selected elements.

Settings

  • Appearance — Preset: color presets for the window. Default: Claude Colors.
  • Window — Window Transparency: 0 to 100 percent in 5 percent steps; higher values make the window darker and more opaque. The default comes from the selected appearance preset.
  • Beta — license state, device ID, Enter License Key… and Deactivate This Device….
  • Feedback — Send Feedback….
  • Diagnostics — Show Diagnostics… and Copy Diagnostics.
  • Credits & Legal — a note on the components used (Sparkle and swift-timecode) and a link to the privacy policy.
  • The settings open from the gear at the bottom of the sidebar.

Field types

There are 23 field types. They are listed in this order in Field and in Add element…:

  • Source TC — source timecode at the playhead.
  • Project TC — timeline timecode at the playhead.
  • Clip Name.
  • Source File — media file name.
  • Reel.
  • Scene / Shot — scene and shot, joined with a dash.
  • Speed / Retime — FREEZE, a percentage (with REV when reversed) or RAMP; nothing at 100 percent, also when reversed.
  • Notes.
  • Angle — multicam angle name.
  • Resolution — width and height, written like 1920x1080.
  • Marker (Note or Name) — the first marker of a ticked type on the clip.
  • Resize / Transform — the average of horizontal and vertical scale in percent, only when a scale is not 100 percent.
  • Stacked Video Clips — one line per video layer.
  • Role Text — see the roles guide.
  • Custom Text — the Label itself.
  • Marker Name, Marker Note, Marker Name + Note — name, note, or both of the first matching marker. The marker types follow the element's setting; the Marker types list is shown for these three fields and for Marker (Note or Name).
  • Source Frame — frame number counted from the first frame of the media file, starting at 0.
  • Stacked Layers — Reel/File + Frame # Block and Stacked Layers — Slate/Timecode Block — two-column blocks with one row per layer.
  • Stabilization — shows the text Stabilized only when stabilization is on.
  • Position / Rotation — position and rotation of the clip, only when not zero.

An element draws nothing when its value is empty. Resize, position and stabilization are only displayed. The speed of a retimed clip is also used to compute Source TC and Source Frame.

Element defaults

  • A new element takes size, text color and opacity, background and anchor from the Bulk Style draft. The draft starts at: Text size 24 (range 12 to 72), Text color white, Text opacity 1, Alignment left, Show background on, Background color black, Background opacity 0.7, Anchor bottom left.
  • X is 0.05 and Y is 0.05 plus 0.05 for each element already in the preset (step 0.01); with a centre or middle anchor the respective value starts at 0.
  • Marker types: Chapter is on; To-Do and Standard are off.

Preset settings

Defaults of a new preset; individual built-in presets can differ.

  • Visible picture — Default: Full Frame. Keep inside visible picture — off.
  • Show stacked layers — off. When on, Source TC, Source Frame, Reel, Scene / Shot and Source File get one extra line per stacked layer.
  • Stack order — Default, V1 on top, V1 on bottom.
  • Layer tag — Name and Number.
  • Hide on generator clips — off. When on, all elements are hidden while the playhead is over a title or generator with no real source clip.

Position Preview

  • Black canvas in the timeline's own aspect ratio; 16:9 if unknown.
  • Grid — off by default; shows an N×N grid (2 to 8, default 3). Snap appears while the grid is on.
  • Crop — the same picker as Visible picture.
  • Shift locks a drag to one axis, Option moves without snapping. A dragged chip stays inside the canvas.
  • Blocks of stacked layers show placeholder sample data, so their size and position are only illustrative.

Limits

  • Live updates are not instant: Final Cut Pro can hold an edit back for a while before it writes it to disk. The refresh button in the status bar (tooltip "Re-scan now") re-scans.
  • The Position Preview is approximate; the real text layout happens in Final Cut Pro.
  • Single-value fields come from the primary clip of the storyline. Clips stacked above appear through the stacked-layer options, and Role Text also reacts to roles of connected clips.

Troubleshooting

The viewer shows "start Host app + select a timeline"

The effect has no data from the Host. Start MalibuBurn Host, add your library and click a timeline. If the Host is running and a timeline is active, click the refresh button in the status bar (tooltip "Re-scan now").

The viewer shows "doesn't fit this timeline"

The playhead could not be matched to the clip list, usually because the project start timecode is wrong. Type the project's start timecode into Project start TC (optional) in the sidebar. The message can also appear when the playhead is parked after the last clip.

The viewer shows "isn't a valid timecode"

The Host's start timecode is well-formed but does not exist at the timeline's frame rate, for example a frames value at or above the frame rate, or drop frame at a rate without drop frame. Correct Project start TC (optional) in the Host.

The viewer shows "gap (no clip at playhead)"

No clip covers the playhead position. This also happens when Hide on generator clips is on and the playhead is over a title or generator without a real source clip.

The viewer shows "no clips found"

The selected timeline has no clips in the data the Host wrote. Re-select the timeline in the Host.

The viewer shows "reinstall the MalibuBurn plugin"

The plugin is older than the Host. See the guide on updating the plugin.

The viewer shows "unsupported timeline frame rate"

The timeline uses a frame rate MalibuBurn does not support, so no burn-in is drawn. The message names the rate.

The viewer shows a message about the Host's data

Messages such as "the Host's data file is missing or too large", "can't read the Host's data file" or "can't read the Host's data — update both the Host app and the plugin" mean the effect cannot read what the Host wrote. Re-select the timeline in the Host. If the message says to update or reinstall, update the Host and the plugin.

An element shows nothing

An element draws nothing when its value is empty, for example Reel on a clip without a reel name. Role Text also draws nothing until a role is picked; the chip shows a warning. Custom Text needs a Label.

Resize, position, stabilization or speed show nothing

These elements only draw something when the clip has a non-default value: Resize / Transform when a scale is not 100 percent, Position / Rotation when position or rotation is not zero, Stabilization when stabilization is on, Speed / Retime for a freeze frame, a speed ramp, or a speed other than 100 percent (a reversed clip at 100 percent shows nothing).

Source Frame is empty

Source Frame is blank when the clip's source frame rate cannot be resolved, for example offline media, and on a gap in the primary storyline.

Detect from Final Cut Pro does nothing

Final Cut Pro must be running with the library open. If an error is shown, follow it; for a permission error see the guide on adding libraries. If the open libraries are already added, nothing happens.

The Host says the license is expired or blocked

A dialog names the reason and offers five buttons: Buy MalibuBurn (purchase page), I Already Have a License (key entry), Download Update (starts the installer download and quits the app), Lost Your License Key? and Quit. While blocked, the viewer shows only the message instead of the burn-in. If the app has been offline too long to verify your license, or has no saved license check yet, it asks you to connect to the internet.

The burn-in looks out of date after an edit

Final Cut Pro can hold an edit back for a while before it writes it to disk. Click the refresh button in the status bar (tooltip "Re-scan now") to re-scan the library.

Send diagnostics to support

Click the gear at the bottom of the sidebar and click Copy Diagnostics, then paste the report into your message. Send Feedback… attaches a diagnostics block automatically.

Erste Schritte

Was MalibuBurn macht

MalibuBurn brennt Clip-Metadaten in den Final-Cut-Pro-Viewer und in deine Exporte: Source-Timecode, Clip- und Dateinamen, Reel, Scene und Shot, Marker, Rollen und mehr. Es besteht aus zwei Teilen. Die App MalibuBurn Host bestimmt, was angezeigt wird und wo. Der MalibuBurn-Effekt in Final Cut Pro zeichnet es.

Bevor du anfängst

Du brauchst macOS 14 oder neuer, Final Cut Pro und das MalibuBurn-Plugin, installiert mit dem MalibuBurn-Installer. Das Plugin liefert den Effekt, den du in Final Cut Pro hinzufügst.

Beim ersten Start fragt die App nach deiner E-Mail-Adresse. Sie ist Pflicht: Der Host zeigt nur diesen Bildschirm, bis du eine eingibst. Die Adresse ordnet deine Testphase dir zu.

Testphase starten

Gib deine E-Mail-Adresse ein und klicke auf Start Trial. Die Taste bleibt deaktiviert, bis die Adresse wie eine E-Mail-Adresse aussieht. Danach öffnet sich eine kurze Anleitung; du kannst sie jederzeit über How MalibuBurn Works im Hilfe-Menü wieder öffnen.

Library hinzufügen und Timeline wählen

Ziehe deine Final-Cut-Pro-Library (die .fcpbundle) in das Fenster von MalibuBurn Host. Klicke dann in der Seitenleiste auf die Timeline, an der du arbeitest. Die Anleitung zum Hinzufügen von Libraries nennt die anderen Wege und erklärt, wie die Timeline automatisch gewählt wird.

Festlegen, was angezeigt wird

Wähle ein Preset in der Preset-Liste oben in der Hauptspalte oder baue ein eigenes, indem du mit Add element… Elemente hinzufügst. Änderungen erreichen Final Cut Pro nach einem Moment; es gibt nichts zu exportieren oder zu speichern.

Effekt in Final Cut Pro hinzufügen

Verbinde in Final Cut Pro eine Adjustment Layer über deiner Timeline und ziehe sie über die volle Länge. Öffne den Effekte-Browser, gehe zu Studio Malibu und ziehe den MalibuBurn-Effekt auf diese Adjustment Layer.

Ergebnis prüfen

Das Einbrennen folgt dem Playhead im Viewer und in jedem Export. Zeigt der Viewer statt Metadaten eine Statuszeile, nennt sie, was fehlt; die Seite zur Fehlersuche listet die häufigen Zeilen. Der Abschnitt Diagnostics in den Einstellungen enthält alles, was der Support braucht.

Library hinzufügen und Timeline wählen

Library ins Fenster ziehen

Ziehe eine Final-Cut-Pro-Library (eine .fcpbundle) auf das Fenster von MalibuBurn Host. Alles, was keine .fcpbundle ist, wird ohne Meldung ignoriert.

Plus-Taste benutzen

Klicke oben links im Fenster auf die Plus-Taste (Tooltip Add Library...) oder in der leeren Seitenleiste auf Add Library.... Wähle im Dateidialog die .fcpbundle. Um in einen Ordner hineinzuschauen, doppelklicke ihn; ein einfacher Klick auf das Bundle und die Open-Taste des Dialogs wählen es.

Geöffnete Libraries erkennen

Klicke bei laufendem Final Cut Pro und geöffneter Library auf Detect from Final Cut Pro. Die Taste ist in der leeren Seitenleiste und als Zauberstab-Symbol in der oberen Zeile. Eine neue Library wird direkt hinzugefügt. Sind mehrere geöffnet, bietet eine Liste mit dem Titel Multiple libraries are open in Final Cut Pro jede Library und Add All an.

Beim ersten Mal fragt macOS, ob MalibuBurn Host Final Cut Pro steuern darf. Erlaube es. Bereits hinzugefügte Libraries werden übersprungen. Ist nichts Neues geöffnet, passiert nichts.

Fehlgeschlagene Erkennung beheben

Schlägt die Erkennung fehl, steht der Grund unter der Taste in der leeren Seitenleiste (in der oberen Zeile ist es der Tooltip). Blockiert macOS die Berechtigung, bekommt die Meldung in der leeren Seitenleiste zwei Aktionen: Open Automation Settings öffnet den Bereich Automation in den Systemeinstellungen, wo MalibuBurn Host Final Cut Pro steuern dürfen muss. Copy Reset Command kopiert einen Terminal-Befehl, der die festgefahrene Berechtigung zurücksetzt; führe ihn aus, stelle sicher, dass Final Cut Pro geöffnet ist, und klicke dann erneut auf Detect from Final Cut Pro.

Timeline wählen

Sobald eine Library gelesen ist, erscheinen ihre Events als einklappbare Karten in der Seitenleiste. Klicke auf eine Timeline, um sie aktiv zu machen; sie zeigt dann burning in. Klicke die aktive Timeline erneut, um die Auswahl aufzuheben. Events ohne Projekt oder Compound Clip werden nicht aufgelistet.

Ist die MalibuBurn-Workflow-Extension in Final Cut Pro geöffnet, folgt der Host der dort aktiven Sequenz. Eine Timeline, die du im Host wählst, ersetzt die frühere Wahl der Extension.

Zwischen kompakter und voller Liste wechseln

Solange eine Timeline aktiv ist, zeigt die Seitenleiste eine kompakte Karte mit Sequenzname, Library und Event. Klicke auf Show All Libraries, um wieder die volle Liste zu sehen, und auf Hide Library List, um zur Karte zurückzukehren.

Library entfernen

Fahre in der vollen Liste über eine Library-Zeile und klicke auf das eingekreiste x. Die Library wird nur aus MalibuBurn entfernt; die Datei bleibt unberührt. Es gibt keine Rückfrage.

Start-Timecode des Projekts setzen

Zeigt das Einbrennen einen Timecode, der nicht zu deiner Timeline passt, trage den Start-Timecode des Projekts unten in der Seitenleiste in Project start TC (optional) ein; das Feld erscheint, solange eine Timeline aktiv ist. Verwende HH:MM:SS:FF oder HH:MM:SS;FF für Drop Frame. Leere das Feld, um zum Wert von Final Cut Pro zurückzukehren. Eine ungültige Eingabe wird ignoriert; der Hinweis unter dem Feld nennt, welcher Wert stattdessen gilt.

Layout aufbauen

Element hinzufügen

Klicke unter der Preset-Liste auf Add element… und wähle ein Feld. Das Element wird dem aktiven Preset hinzugefügt und ausgewählt. Wurde zuvor ein Element kopiert, steht Paste element an erster Stelle.

Elemente auswählen, ausblenden und entfernen

Jedes Element ist ein Chip. Klicke auf den Haken, um es ein- oder auszublenden, auf den Namen, um es zum Bearbeiten auszuwählen (klicke den einzigen gewählten Chip erneut, um die Auswahl aufzuheben), und auf das x, um es zu entfernen. Shift-Klick erweitert die Auswahl. Die Löschen-Taste (⌫) löscht die ausgewählten Elemente. Es gibt keine Rückfrage und kein Rückgängig.

Element kopieren

Klicke einen Chip mit der rechten Maustaste und wähle Copy. Wähle dann Paste aus dem Chip-Menü oder Paste element unter Add element…. Das eingefügte Element landet am Ende des aktiven Presets, auch über Presets hinweg.

Feld und Label ändern

Wähle ein Element. Wähle im Tile Editor ein anderes Field oder tippe ein Label. Bei den meisten Feldern ist das Label ein Präfix vor dem Wert; bei gestapelten Layern erscheint es in einem Tag wie [label V1]. Bei Custom Text ist das Label der Text selbst.

Element positionieren

Wähle im Tile Editor einen Anchor im 3×3-Raster und stelle dann X und Y mit den Reglern oder per Zahleneingabe ein. Bei einem linken, rechten, oberen oder unteren Anker ist der Wert der Abstand von dieser Kante des sichtbaren Bildes (0 bis 1). Bei einem mittigen Anker ist es der Versatz von der Mitte (−0,5 bis 0,5). Beim Wechsel des Ankers bleibt das Element an seiner Stelle auf dem Bildschirm.

Du kannst das Element auch in der Position Preview ziehen. Es rastet an den Kanten und der Mitte des Bildes sowie an anderen Elementen ein. Nach dem Ziehen wird der Anker auf jeder bewegten Achse die nächste Kante oder Mitte, und X und Y werden angepasst. Halte Shift, um auf eine Achse zu sperren (Shift zu Beginn des Ziehens schaltet das Element auch in der Auswahl um), und Option, um ohne Einrasten zu bewegen.

Text und Hintergrund gestalten

Stelle unter Text Text size (12 bis 72), Text color, Text opacity und Alignment ein. Alignment wirkt nur bei mehrzeiligem Inhalt. Schalte unter Background Show background ein oder aus und stelle Background color und Background opacity ein.

Alle Elemente auf einmal umgestalten

Öffne das Tile Bulk Style mit den Symbolen in der Kopfzeile über der Preset-Liste. Stelle den Entwurf für Text, Hintergrund oder Anker ein und klicke auf Apply to all. Die Entwürfe für Text und Hintergrund überschreiben sofort jedes Element des Presets; dupliziere das Preset zuerst, wenn du den alten Stand behalten willst. Der Anker-Entwurf rechnet die Positionen auf den neuen Anker um, die Elemente bleiben also auf dem Bildschirm an ihrer Stelle. Neue Elemente übernehmen Größe, Farben, Deckkraft, Hintergrund und Anker aus dem Entwurf, nicht aber die Ausrichtung.

Position Preview im eigenen Fenster öffnen

Klicke auf das Symbol oben rechts in der Vorschau, um Position Preview als eigenes Fenster zu öffnen. Die Auswahl wird mit dem Hauptfenster geteilt. Das eigene Fenster enthält die Vorschau mit ihrer Werkzeugleiste (Grid, Snap, Crop); die Tiles Editor, Settings und Bulk Style bleiben im Hauptfenster.

Clip-Rollen anzeigen

Role-Text-Element hinzufügen

Klicke auf Add element… und wähle Role Text. Das Element startet im Modus Role Name. Es zeigt nichts, bis mindestens eine Rolle gewählt ist; der Editor weist mit der Meldung „None selected yet — this element won't show anything until you pick one below.“ darauf hin.

Rollen wählen

Wähle das Element und öffne seine Liste Roles im Tile Editor. Die Rollen sind unter Video Roles, Audio Roles und Caption Roles gruppiert. Hake jede Rolle an, die das Element auslösen soll. Eine Hauptrolle deckt alle ihre Unterrollen und die der Hauptrolle selbst zugewiesenen Clips ab; öffne ihren Pfeil nur, um einzelne Unterrollen zu wählen. All sub-roles hakt nur die benannten Unterrollen dieser Hauptrolle an.

Die Liste wird aus den hinzugefügten Libraries gefüllt. Sind keine Rollen verfügbar, steht dort „No roles found — pick a library/timeline first.“

Festlegen, was das Element zeigt

Stelle Show auf einen von drei Modi. Custom Text zeigt das Label, solange ein Clip mit einer gewählten Rolle aktiv ist. Media Filename zeigt den Namen des aktiven Clips, den die App anstelle eines Dateinamens verwendet. Role Name zeigt den Namen der Rolle selbst. In den letzten beiden Modi ist das Label ein Präfix, wenn es nicht leer ist.

Rollen nach dem Import eines Presets prüfen

Die Rollenauswahl eines Presets gehört zu dem Projekt, für das es erstellt wurde; ein importiertes oder geteiltes Preset passt daher womöglich nicht zu den Rollen deines Projekts. Prüfe die gewählten Rollen nach dem Import eines Presets.

Presets verwalten

Preset wählen

Benutze die Liste oben in der Hauptspalte. MalibuBurn bringt eingebaute Presets mit, darunter Netflix QC Layout, Conform und Colorist. Eingebaute Presets lassen sich direkt bearbeiten, aber nicht umbenennen oder löschen.

Eigenes Preset anlegen

Klicke neben der Liste auf die Plus-Taste. Sie dupliziert das aktuelle Preset unter dem Namen <Name> Copy und öffnet das Tile Settings, damit du es umbenennen kannst. Klicke später auf den Stift, um ein eigenes Preset umzubenennen.

Exportieren und importieren

Öffne im Tile Settings Preset actions und wähle Export preset…, um das Preset als JSON-Datei zu schreiben, oder Import preset…, um eine zu lesen. Ein Import wird immer zu einem normalen Preset und wird aktiviert. Existiert der Name bereits, wird „ (Imported)“ angehängt; nichts wird überschrieben.

Zurücksetzen oder löschen

Bei einem eingebauten Preset bietet Preset actions Reset to factory default…, das deine Änderungen nach einer Rückfrage verwirft. Bei eigenen Presets gibt es Delete preset, das sofort wirkt; das letzte verbleibende Preset lässt sich nicht löschen.

Sichtbares Bild festlegen

Unter Canvas legt Visible picture die Bildfläche fest, auf die sich die Positionen der Elemente beziehen: Full Frame, 2.39:1, 2.35:1, 1.85:1, 4:3 oder Custom. Eine Änderung verschiebt Elemente, weil X und Y Anteile dieser Fläche sind. Die Position Preview zeigt sie als etwas hellere Fläche. Custom nimmt Breite und Höhe, zum Beispiel 1920 und 1080; Komma oder Punkt gelten als Dezimaltrenner. Du kannst Elemente weiterhin in die Balken um das Bild setzen, solange Keep inside visible picture aus ist, was standardmäßig der Fall ist; aus dem Bildfeld selbst verlassen sie nie.

Änderungen werden automatisch gespeichert

Presets werden bei jeder Änderung automatisch gespeichert. Es gibt keine Speichern-Taste.

Timeline gegen FCPXML prüfen

Timeline exportieren

Exportiere in Final Cut Pro dieselbe Timeline, die du in MalibuBurn gewählt hast, als FCPXML.

Prüfung starten

Wähle die Timeline in der Seitenleiste und öffne das Tile Validate mit den Symbolen in der Kopfzeile oder das erweiterte Fenster Validate Against FCPXML. Ziehe die .fcpxml- oder .fcpxmld-Datei auf die Ablagefläche oder klicke auf Choose FCPXML.... Ohne gewählte Timeline fordert das Tile dich auf, zuerst in der Seitenleiste eine zu wählen.

Ergebnis lesen

Die Prüfung vergleicht die von MalibuBurn aufgelöste Clip-Liste mit der FCPXML. PASS bedeutet, dass jeder verglichene Clip in Position auf der Timeline, Dauer und Name (bei einfachen Clips auch im Source-Start) übereinstimmt und es keine fehlenden oder zusätzlichen Einträge gibt. FAIL bedeutet, dass es Abweichungen gibt. Das Tile zeigt PASS oder FAIL, eine Zusammenfassung und zwei Zahlen; das Fenster listet die Abweichungen, gruppiert in Clips nur in der FCPXML, Clips nur in der Liste von MalibuBurn und Feldabweichungen bei zugeordneten Clips, bis zu 200 Zeilen je Gruppe.

Die richtige Timeline verwenden

Enthält die FCPXML keine Timeline mit dem gewählten Namen, vergleicht MalibuBurn eine Ersatz-Timeline aus der Datei, und das Fenster warnt, dass es nicht die hier gewählte Timeline ist. Das Tile zeigt diese Warnung nicht. Exportiere die FCPXML für die gewählte Timeline, damit der Vergleich gültig ist.

Final-Cut-Pro-Plugin aktualisieren

Wissen, was was aktualisiert

Die Host-App sucht mit Sparkle selbst nach Updates; Check for Updates… im App-Menü prüft auf Abruf. Das Final-Cut-Pro-Plugin aktualisiert der Host: Ist das installierte Plugin älter als der Host, meldet das ein Banner oben im Fenster und installiert das passende Plugin.

Danach Final Cut Pro neu starten

Meldet das Banner „Final Cut Pro plugin updated to build“, starte Final Cut Pro neu. Es behält bis dahin die alte Version geladen.

Passwort eingeben, wenn danach gefragt wird

Wurde das Plugin vom Installer installiert, klicke im Banner auf Update Plugin…. macOS fragt einmal nach deinem Passwort; spätere Updates installieren sich selbst.

App-Verwaltung erlauben

Sagt das Banner, dass macOS dem MalibuBurn Host das Ersetzen des Plugins nicht erlaubt, klicke auf Open App Management Settings, schalte die Berechtigung für MalibuBurn Host ein und starte den Host neu. Ist sie schon an, nimm den vollständigen Installer.

Mit dem Installer installieren oder reparieren

Download Installer oder Download Full Installer lädt den aktuellen MalibuBurn-Installer in deinem Browser herunter; führe ihn danach aus. Nutze ihn, wenn das Plugin gar nicht installiert ist oder ein automatisches Update fehlgeschlagen ist.

Fehlenden Effekt wiederherstellen

Sagt das Banner, dass der Effekt im Ordner Motion Templates fehlt, klicke einmal auf Open MalibuBurn, um ihn neu zu installieren, und starte dann Final Cut Pro neu.

Referenz

Voraussetzungen

  • macOS 14 oder neuer.
  • Final Cut Pro mit installiertem MalibuBurn-Plugin. Der Effekt heißt MalibuBurn und liegt in der Kategorie Studio Malibu.

Fenster und Tiles

  • Das Host-Fenster öffnet mit 1200 × 760 und lässt sich nicht kleiner als 840 × 640 ziehen.
  • Editor — das gewählte Element: Element, Position, Text und Background, bei manchen Feldern ein weiterer Abschnitt. Standardmäßig offen.
  • Settings — die eigenen Einstellungen des Presets: Preset, Canvas, Stacked layers, Visibility. Standardmäßig offen.
  • Bulk Style — Entwürfe für Text, Hintergrund und Anker mit Apply to all. Standardmäßig geschlossen.
  • Validate — vergleicht die Timeline mit einer exportierten FCPXML. Standardmäßig geschlossen.
  • Tiles öffnen und schließen mit den Symbolen in der Kopfzeile über der Preset-Liste. Wird der Inhaltsbereich schmaler als 860 Punkte, werden offene Tiles geschlossen; Tiles, die du bei schmalem Bereich öffnest, schweben über der Hauptspalte.

Menüs und Kurzbefehle

  • MalibuBurn Help (Help-Menü) — öffnet diese Hilfeseiten im Browser.
  • How MalibuBurn Works (Hilfe-Menü) — öffnet die Anleitung erneut.
  • Send Feedback… (Hilfe-Menü, ⌘?) — öffnet den Feedback-Dialog.
  • Check for Updates… (App-Menü, nicht in Mac-App-Store-Builds) — sucht nach einer neuen Host-Version.
  • Buy MalibuBurn (App-Menü) — öffnet die Kaufseite; sichtbar, bis eine Lizenz bestätigt ist.
  • Das Menüleistensymbol — ein Popover mit Status, aktiver Timeline und Libraries (ein Klick auf eine Library öffnet das Host-Fenster), einem kleinen Symbol in der oberen Zeile, das MalibuBurn Host öffnet (sein Tooltip ist Open MalibuBurn Host), und einer Fußzeile mit Settings (⌘,) und Quit (⌘Q).
  • Löschen-Taste (⌫) — löscht die ausgewählten Elemente.

Einstellungen

  • Appearance — Preset: Farbvorgaben für das Fenster. Standard: Claude Colors.
  • Window — Window Transparency: 0 bis 100 Prozent in 5-Prozent-Schritten; höhere Werte machen das Fenster dunkler und undurchsichtiger. Der Standardwert kommt aus der gewählten Farbvorgabe.
  • Beta — Lizenzstatus, Geräte-ID, Enter License Key… und Deactivate This Device….
  • Feedback — Send Feedback….
  • Diagnostics — Show Diagnostics… und Copy Diagnostics.
  • Credits & Legal — ein Hinweis auf die verwendeten Komponenten (Sparkle und swift-timecode) und ein Link zur Datenschutzerklärung.
  • Die Einstellungen öffnen sich über das Zahnrad unten in der Seitenleiste.

Feldtypen

Es gibt 23 Feldtypen. Sie stehen in dieser Reihenfolge in Field und in Add element…:

  • Source TC — Source-Timecode am Playhead.
  • Project TC — Timeline-Timecode am Playhead.
  • Clip Name.
  • Source File — Name der Mediendatei.
  • Reel.
  • Scene / Shot — Scene und Shot, mit Bindestrich verbunden.
  • Speed / Retime — FREEZE, ein Prozentwert (mit REV bei Rückwärtswiedergabe) oder RAMP; bei 100 Prozent nichts, auch rückwärts.
  • Notes.
  • Angle — Name des Multicam-Angles.
  • Resolution — Breite und Höhe, geschrieben wie 1920x1080.
  • Marker (Note or Name) — der erste Marker eines angehakten Typs am Clip.
  • Resize / Transform — Mittelwert aus horizontaler und vertikaler Skalierung in Prozent, nur wenn eine Skalierung nicht 100 Prozent ist.
  • Stacked Video Clips — eine Zeile je Video-Layer.
  • Role Text — siehe die Anleitung zu Rollen.
  • Custom Text — das Label selbst.
  • Marker Name, Marker Note, Marker Name + Note — Name, Notiz oder beides des ersten passenden Markers. Die Markertypen folgen der Einstellung des Elements; die Liste Marker types wird für diese drei Felder und für Marker (Note or Name) angezeigt.
  • Source Frame — Bildnummer ab dem ersten Bild der Mediendatei, beginnend bei 0.
  • Stacked Layers — Reel/File + Frame # Block und Stacked Layers — Slate/Timecode Block — zweispaltige Blöcke mit einer Zeile je Layer.
  • Stabilization — zeigt den Text Stabilized nur, wenn die Stabilisierung an ist.
  • Position / Rotation — Position und Rotation des Clips, nur wenn nicht null.

Ein Element zeichnet nichts, wenn sein Wert leer ist. Resize, Position und Stabilisierung werden nur angezeigt. Die Geschwindigkeit eines retimten Clips fließt auch in die Berechnung von Source TC und Source Frame ein.

Element-Standardwerte

  • Ein neues Element übernimmt Größe, Textfarbe und Deckkraft, Hintergrund und Anker aus dem Entwurf in Bulk Style. Der Entwurf beginnt mit: Text size 24 (Bereich 12 bis 72), Text color weiß, Text opacity 1, Alignment links, Show background an, Background color schwarz, Background opacity 0,7, Anchor unten links.
  • X ist 0,05 und Y ist 0,05 plus 0,05 für jedes bereits im Preset vorhandene Element (Schritt 0,01); bei einem mittigen Anker beginnt der jeweilige Wert bei 0.
  • Marker types: Chapter ist an; To-Do und Standard sind aus.

Preset-Einstellungen

Standardwerte eines neuen Presets; einzelne eingebaute Presets können abweichen.

  • Visible picture — Standard: Full Frame. Keep inside visible picture — aus.
  • Show stacked layers — aus. Wenn an, bekommen Source TC, Source Frame, Reel, Scene / Shot und Source File eine zusätzliche Zeile je gestapeltem Layer.
  • Stack order — Default, V1 on top, V1 on bottom.
  • Layer tag — Name und Number.
  • Hide on generator clips — aus. Wenn an, werden alle Elemente ausgeblendet, solange der Playhead über einem Titel oder Generator ohne echten Quell-Clip steht.

Position Preview

  • Schwarze Fläche im Seitenverhältnis der Timeline; 16:9, wenn unbekannt.
  • Grid — standardmäßig aus; zeigt ein N×N-Raster (2 bis 8, Standard 3). Snap erscheint, solange das Raster an ist.
  • Crop — dieselbe Auswahl wie Visible picture.
  • Shift sperrt das Ziehen auf eine Achse, Option bewegt ohne Einrasten. Ein gezogener Chip bleibt innerhalb der Fläche.
  • Blöcke gestapelter Layer zeigen Platzhalterdaten; ihre Größe und Position sind daher nur Anhaltspunkte.

Grenzen

  • Live-Updates sind nicht sofort: Final Cut Pro kann eine Änderung eine Weile zurückhalten, bevor es sie auf die Platte schreibt. Die Aktualisieren-Taste in der Statusleiste (Tooltip „Re-scan now“) liest neu ein.
  • Die Position Preview ist nur eine Näherung; das echte Textlayout passiert in Final Cut Pro.
  • Einzelwert-Felder stammen vom Primärclip der Storyline. Darüber gestapelte Clips erscheinen über die Stacked-Layer-Optionen, und Role Text reagiert auch auf Rollen verbundener Clips.

Fehlersuche

Der Viewer zeigt „start Host app + select a timeline“

Der Effekt hat keine Daten vom Host. Starte MalibuBurn Host, füge deine Library hinzu und klicke auf eine Timeline. Läuft der Host und ist eine Timeline aktiv, klicke in der Statusleiste auf die Aktualisieren-Taste (Tooltip „Re-scan now“).

Der Viewer zeigt „doesn't fit this timeline“

Der Playhead konnte der Clip-Liste nicht zugeordnet werden, meist weil der Start-Timecode des Projekts nicht stimmt. Trage den Start-Timecode des Projekts in der Seitenleiste in Project start TC (optional) ein. Die Meldung kann auch erscheinen, wenn der Playhead hinter dem letzten Clip steht.

Der Viewer zeigt „isn't a valid timecode“

Der Start-Timecode im Host ist wohlgeformt, existiert aber bei der Bildrate der Timeline nicht, zum Beispiel ein Bildwert ab der Bildrate oder Drop Frame bei einer Rate ohne Drop Frame. Korrigiere Project start TC (optional) im Host.

Der Viewer zeigt „gap (no clip at playhead)“

Kein Clip deckt die Position des Playheads ab. Das passiert auch, wenn Hide on generator clips an ist und der Playhead über einem Titel oder Generator ohne echten Quell-Clip steht.

Der Viewer zeigt „no clips found“

Die gewählte Timeline hat in den vom Host geschriebenen Daten keine Clips. Wähle die Timeline im Host erneut.

Der Viewer zeigt „reinstall the MalibuBurn plugin“

Das Plugin ist älter als der Host. Siehe die Anleitung zum Aktualisieren des Plugins.

Der Viewer zeigt „unsupported timeline frame rate“

Die Timeline hat eine Bildrate, die MalibuBurn nicht unterstützt, deshalb wird nichts eingebrannt. Die Meldung nennt die Rate.

Der Viewer zeigt eine Meldung zu den Daten des Hosts

Meldungen wie „the Host's data file is missing or too large“, „can't read the Host's data file“ oder „can't read the Host's data — update both the Host app and the plugin“ bedeuten, dass der Effekt nicht lesen kann, was der Host geschrieben hat. Wähle die Timeline im Host erneut. Fordert die Meldung zu einem Update oder einer Neuinstallation auf, aktualisiere Host und Plugin.

Ein Element zeigt nichts

Ein Element zeichnet nichts, wenn sein Wert leer ist, zum Beispiel Reel bei einem Clip ohne Reel-Namen. Role Text zeichnet ebenfalls nichts, bis eine Rolle gewählt ist; der Chip zeigt eine Warnung. Custom Text braucht ein Label.

Resize, Position, Stabilization oder Speed zeigen nichts

Diese Elemente zeichnen nur etwas, wenn der Clip einen vom Standard abweichenden Wert hat: Resize / Transform, wenn eine Skalierung nicht 100 Prozent ist, Position / Rotation, wenn Position oder Rotation nicht null sind, Stabilization, wenn die Stabilisierung an ist, Speed / Retime bei einem Standbild, einer Geschwindigkeitsrampe oder einer Geschwindigkeit ungleich 100 Prozent (ein rückwärts laufender Clip bei 100 Prozent zeigt nichts).

Source Frame ist leer

Source Frame bleibt leer, wenn die Quell-Bildrate des Clips nicht ermittelt werden kann, zum Beispiel bei Offline-Medien, und auf einer Lücke in der Primär-Storyline.

Detect from Final Cut Pro tut nichts

Final Cut Pro muss laufen und die Library geöffnet sein. Wird ein Fehler angezeigt, folge ihm; bei einem Berechtigungsfehler siehe die Anleitung zum Hinzufügen von Libraries. Sind die geöffneten Libraries schon hinzugefügt, passiert nichts.

Der Host meldet, die Lizenz sei abgelaufen oder gesperrt

Ein Dialog nennt den Grund und bietet fünf Tasten: Buy MalibuBurn (Kaufseite), I Already Have a License (Schlüsseleingabe), Download Update (startet den Installer-Download und beendet die App), Lost Your License Key? und Quit. Solange gesperrt ist, zeigt der Viewer statt des Einbrennens nur die Meldung. War die App zu lange offline, um deine Lizenz zu prüfen, oder gibt es noch keine gespeicherte Lizenzprüfung, bittet sie dich, eine Internetverbindung herzustellen.

Das Einbrennen wirkt nach einer Änderung veraltet

Final Cut Pro kann eine Änderung eine Weile zurückhalten, bevor es sie auf die Platte schreibt. Klicke in der Statusleiste auf die Aktualisieren-Taste (Tooltip „Re-scan now“), um die Library neu einzulesen.

Diagnose an den Support schicken

Klicke auf das Zahnrad unten in der Seitenleiste und dann auf Copy Diagnostics; füge den Bericht in deine Nachricht ein. Send Feedback… hängt automatisch einen Diagnoseblock an.
