Getting started

What Malibu Conform does

Malibu Conform takes a Final Cut Pro project that you exported as FCPXML and prepares it for DaVinci Resolve Studio. It writes a Resolve-ready FCPXML, a manifest and a conform report. Optionally it then imports the timeline into Resolve and applies the transforms there. The conform covers picture only; audio is out of scope.

Before you start

You need macOS 14.0 or later and a project exported from Final Cut Pro.

The automatic Resolve step needs DaVinci Resolve Studio; the app warns that the free edition does not include the Python scripting API. Without Resolve you still get the conformed files and can import them yourself (see the guide on manual import).

The Resolve step runs on Python 3.10 or 3.11. The app uses a Python 3.11 bundled in the app when the build contains one and otherwise looks for an installed 3.10 or 3.11. On first launch the app can ask for your email address so that support can find and extend your trial access.

Export from Final Cut Pro

In Final Cut Pro, select the project (the assembled timeline, not an event or the library) and export it with File ▸ Export XML. Malibu Conform reads FCPXML versions 1.10 to 1.14, either as a .fcpxml file or as a .fcpxmld bundle. A file without a project timeline, such as an event export, is blocked by the preflight check or reported as "nothing conformed".

Conform the file

Start Malibu Conform and drag the file onto the drop zone Drop FCPXML or .fcpxmld here, or click the zone and pick the file.

Leave the options at their defaults and click Conform for Resolve.

If the preflight check has anything to report, even informational, a sheet lists it first. Click Conform Anyway to continue; if there is only information, the button reads Conform. A hard block means the file cannot be conformed; export the project again and retry.

Read the result

When the run finishes the window shows the duration, a summary line (clips, multicams, compounds inlined, transforms, effects removed), the output files and any warnings. The buttons are Open Output Folder, View Report, Import into Resolve and New Conform.

The files land in the output folder, by default Movies/MalibuConform in your home folder: <input name>_Conform.fcpxml, manifest.json, ConformReport.md and ConformReport.pdf, plus a reference movie if you added one.

What happens in Resolve

With Drive Resolve after export switched on and Resolve Studio set up, Malibu Conform starts Resolve if it is not running. It imports the FCPXML as a timeline named after your file with the suffix _Conform into the project that is open in Resolve, applies the transforms and reads the values back to check them. Clips with several keyframes are left as Resolve imported them and only get a marker.

With the option switched off, a sheet with import instructions opens instead.

Set up DaVinci Resolve

Check the setup

Open the app's Settings (the gear icon in the header), choose the tab Resolve and click Check Resolve Setup. The list shows Installed, Studio Edition, Scripting Available and Python.

On the very first launch a setup window opens. Click Check Setup to run the checks; the button then reads Re-check. Skip closes the window and Done appears once everything is ready. Its list is worded differently from the Settings list, for example "Studio edition detected". If a later launch finds something missing, a banner offers Check Setup.

Use the Studio edition

Automatic mode needs DaVinci Resolve Studio; the app's hint says the free edition does not include the Python scripting API. The check looks for Resolve and its scripting library in the default location in the Applications folder, so a copy installed elsewhere is reported as not installed. It tests for those files, not for a license.

Enable external scripting

In DaVinci Resolve open the Preferences and set External scripting using to Local. The app's setup hint names the path Preferences → System → External Scripting Using → Local; the Resolve step's own message names Preferences > General. Without the setting Resolve may be running but does not answer, and the Resolve step stops with a message that tells you to enable it.

Open a project in Resolve

Malibu Conform imports into the project that is currently open in Resolve and never creates one. If no project is open within 20 seconds, the Resolve step stops with "No project is open in Resolve. Open (or create) a project, then run again." The files and the report are still written; the failure appears as a warning "Resolve driver failed".

Let Malibu Conform start Resolve

If Resolve is not running, Malibu Conform starts it and waits up to 180 seconds for it to answer. A Resolve that is already running but does not answer is not restarted.

Switch the Resolve step on or off

Use Drive Resolve after export, either in the options of the main window (visible once a file is chosen) or in Settings under Resolve. It is on by default. If the setup check fails when the app starts, the checkbox in the main window starts out off for that session while Settings still shows your stored choice.

The checkbox in the main window and the one in Settings are the same setting: a change in either place applies at once and is saved.

Import the conformed file into Resolve yourself

When you need this

Use the manual import when Drive Resolve after export is off, or when the Resolve step reported an error. If the option was off, the instructions open on their own after the run; otherwise click Import into Resolve in the result window.

Import the timeline

In DaVinci Resolve Studio choose File → Import → Timeline… and pick the file named <input name>_Conform.fcpxml that the sheet shows. Show FCPXML in Finder reveals it.

Switch on three import options

In the import dialog enable Use color information, Mixed frame rate format: Final Cut Pro X and Automatically import source clips into media pool. The app's instructions state that without these three options the conform looks correct in the Inspector but drifts visually, and that the media pool option links the clips to your media.

What a manual import does not include

The red "Effect Removed" and "Transform Check" markers, the yellow "Keyframed Transform" marker and the read-back of transform values come from the Resolve step. A manual import has none of them. Markers for adjustment layers and your original Final Cut Pro markers are written into the FCPXML and arrive either way. Removed filters are listed in the conform report and in manifest.json.

Read the conform report and markers

Open the report

Click View Report in the result window. It opens ConformReport.pdf from the output folder. The same report is also there as Markdown, ConformReport.md; View Report opens that file when the PDF could not be written.

What the report lists

The report has a summary and sections such as Critical — Manual Review Required, Warnings, Removed Effects, Multicam Resolutions, Transforms Applied, Source Media Rasters, Source Media, Cross-Clip Adjustment Layers, Custom LUTs Detected and Reference Movie. It closes with notes for the colorist.

Removed effects

Video filters on clips are removed, including color filters, because none is translated to Resolve. A filter removed from a clip on the main storyline is listed under Removed Effects with a suggestion for how to rebuild it in Resolve. A filter removed from a connected clip appears under Warnings instead and gets no marker in Resolve. Custom LUT filters are removed too and are also listed under Custom LUTs Detected.

Markers in Resolve

Markers on clips come from two places. The conform writes a marker "Adjustment Layer: <name>" on the first clip an adjustment layer covers. The Resolve step sets the others. A red marker named "Effect Removed" followed by the filter name shows a removed filter. A red marker named "Malibu Conform: Transform Check" lists transform values that did not arrive as intended. A yellow marker named "Keyframed Transform" means the clip has more than one transform keyframe and was left as Resolve imported it; check the animation against your reference.

Warnings in the result window

The result window shows the first ten warnings in the order they were recorded; the rest are in the report. The report lists errors under Critical — Manual Review Required and warnings under Warnings; information entries are only counted in its summary. A red dot marks an error, orange a warning and grey information.

Handle compound clips, multicams and sync clips

What happens by default

In the normal case multicam clips are replaced by their active angle and sync clips are unwrapped to their primary video clip, so Resolve receives plain clips. A few cases stay as they are and get a warning, for example a retimed wrapper that carries connected video. A compound clip is flattened when it reduces to a single clip. A compound with several clips stays a compound clip and the conform records the information "Compound contains N elements — kept as compound". A compound whose only content is a title is not flattened and is reported with "Inner element is not inlinable".

Flatten compounds with several clips

Switch on Aggressive compound inlining in the options before you click Conform for Resolve, or in Settings under General. Malibu Conform then takes the first inner clip of such a compound when it is an asset clip and drops the rest; if the first item is something else, the compound stays as it is. Nested clip arrangements can be lost, so use it only when the compounds in your edit are wrappers and nothing more. The option is off by default.

Find what stayed unconformed

If clips with picture remain sync, compound or multicam clips, the conform adds a warning with their number: they import into Resolve as Compound Clips that cannot be graded per clip. The warnings for each clip give the reason.

Connected clips

Clips on lanes and secondary storylines are conformed in the FCPXML, but their transforms are not applied in Resolve: the Resolve step only addresses clips on video track 1. A note in the warnings shows how many connected clips were conformed.

Conform dailies proxies that carry burn-in bars

When you need this

Use this when your edit was cut on dailies proxies with extra burn-in rows that the camera originals do not have. The conform then calculates clips whose source raster matches a proxy raster you entered for the camera originals; clips with other rasters are not changed.

Add a proxy raster

Open Settings, choose the tab Proxies and click Add Proxy Raster. A new row starts with the placeholder sizes 1920 × 1080 for the proxy and 3840 × 2160 for the original; replace both with your sizes. Enter Proxy size and Original size. The bars are worked out from the two sizes: the picture area is the largest part of the proxy with the original's aspect ratio, centered, and an odd leftover pixel goes to the bottom or right. A row with edited bars no longer follows the sizes.

Set uneven bars

Edit any bar under Bars (px) (Top, Bottom, Left, Right) to enter your own values. The row then shows "Custom bars."; click Work out from sizes to return to the automatic values. Use the trash button to remove a row.

Run the conform

The rows are read fresh at every conform run. The conform report lists the raster sizes of your project under Source Media Rasters. Relink to the camera originals in Resolve before you check the picture; until then the proxies look too small.

Known limits

Clips with keyframes are not re-based to the camera original; the conform warns for each of them, and you check size and position after relinking.

Reference

Requirements and versions

  • macOS 14.0 or later.
  • Input: FCPXML versions 1.10 to 1.14 as .fcpxml file or .fcpxmld bundle, exported from a Final Cut Pro project.
  • Resolve step: DaVinci Resolve Studio with external scripting set to Local and Python 3.11. The app uses a Python 3.11 bundled with the build when there is one, and otherwise falls back to a python.org 3.11, a Homebrew 3.10 or 3.11, or /usr/bin/python3 if that is 3.10 or 3.11.
  • Verified against DaVinci Resolve Studio 21.1.0.17 only; other Resolve versions are untested.

Main window

  • Drop FCPXML or .fcpxmld here — the drop zone; click it to choose a file instead.
  • Drive Resolve after export — Standard: on; the main-window checkbox starts out off for the session if the Resolve setup check fails when the app launches. Runs the Resolve step after the files are written.
  • Aggressive compound inlining — Standard: off. Flattens compounds with several clips by keeping only the first.
  • Include reference movie — Standard: on. Takes the movie chosen under Reference Movie into the output.
  • Burn in timecode if missing — Standard: on. Adds the timeline start timecode as a text overlay on the reference movie unless its file name suggests it already has timecode.
  • Select... — chooses a reference movie. Change... — chooses the output directory.
  • Conform for Resolve — starts the preflight check and the conform.

The options appear once a file is chosen.

Settings

  • General — Aggressive compound inlining (off), Include reference movie (on), Burn in timecode if missing (on, available only while a reference movie is included) and the output folder with Choose.... The default output folder is Movies/MalibuConform in your home folder.
  • Resolve — Drive Resolve after export (on), the status list and Check Resolve Setup.
  • Proxies — proxy rasters with burn-in bars; see the guide on proxies.
  • License — shows status, email and device ID; Redeem License Key... and Deactivate This Device....
  • Diagnostics — Verbose logging (off), Open Log Directory and Send Feedback….

The options in the main window and the matching options here are the same settings: a change in either place applies at once and is saved. The Proxies tab is read at every run.

Menus and shortcuts

  • Malibu Conform ▸ Check for Updates… looks for a new version.
  • Help ▸ Send Feedback… opens the feedback window; the shortcut is ⌘?.

Output files

  • <input name>_Conform.fcpxml — the Resolve-ready FCPXML. It keeps the version of the input.
  • manifest.json — the transforms and removed filters that the Resolve step reads.
  • ConformReport.md — the conform report in Markdown.
  • ConformReport.pdf — the same report as an A4 PDF. If it cannot be written, the conform records an information message and the Markdown report is still there.
  • reference_<file name> — a copy of the reference movie; <name>_TC.mp4 when timecode was burned in.

Reference movie

A reference movie must have a video track. It is validated, copied into the output folder and listed in the report. Whether it already carries burned-in timecode is guessed from the file name: names containing "_tc", "timecode" or "burnin" count as having it.

Warning severities

A message is a hard block, an error, a warning or information. A hard block stops the conform before it starts. Only the preflight findings appear before the run; with errors or warnings the continue button reads Conform Anyway, with only information it reads Conform. Warnings from the conform and from the Resolve step appear afterwards in the result window and the report.

Limits

  • Picture only. Audio is out of scope; connected audio of a flattened wrapper is dropped.
  • Transforms are applied to clips on video track 1 only. Connected clips are conformed in the FCPXML but not touched in Resolve.
  • Video filters on clips are removed and reported; none is translated to Resolve. On connected clips they are reported as a warning only and get no marker in Resolve.
  • Clips with more than one transform keyframe keep what Resolve imported and get a yellow marker; the Resolve step cannot write keyframes. Connected keyframed clips get no marker.
  • Adjustment layers are not applied to the clips they cover. A title that is an adjustment layer with a transform, sitting on the main storyline, is removed from the output, marked on the first clip it covers and listed in the report; adjustment layers elsewhere are not detected.
  • For audition clips only the active pick reaches Resolve.
  • Pan and Tilt units were measured for Resolve's Crop and Fit scaling modes only.
  • The Studio check tests for a file in the default Resolve location, not for a license.

Troubleshooting

The file is rejected before the conform

"This appears to be an Event XML (clip-only) export": you exported an event or library without a project. Select the project in Final Cut Pro and export it again. "No timeline sequence found in FCPXML" means the file holds no project and no timeline at all; export the project again. "FCPXML … is not supported. Need 1.10–1.14": the file has a different FCPXML version; the message names Final Cut Pro 10.6.5 or newer as the source.

The conform finished but nothing changed

The report says that no multicam or compound clips were in a conformable project timeline. The file is most likely an event or library export, or the exported project is empty. Select the project in Final Cut Pro and export it again.

Clips stay compound clips in Resolve

Compounds with several clips are kept as compounds by default. Switch on Aggressive compound inlining if you accept that only the first clip is kept. See the guide on compound clips.

Resolve does not answer

"Cannot connect to Resolve. It is running, but scripting does not answer": set External scripting using to Local in Resolve's Preferences and run the conform again. "It was started but did not answer within 180 s": wait until Resolve has finished starting, check the same setting and retry.

No project is open in Resolve

Open or create a project in Resolve and run the conform again. Malibu Conform never creates a project itself.

Resolve cannot import the file

"Resolve failed to import the FCPXML": check that all source media is accessible. The FCPXML in the output folder can also be imported by hand; see the guide on manual import.

No compatible Python found

"No compatible Python 3.10 or 3.11 found": the bundled Python could not be used and no installed 3.10 or 3.11 was found. Install Python 3.11 from python.org or with Homebrew. Python 3.12 and later does not work with Resolve's scripting library.

A "Transform Check" marker appears

Resolve can clip values silently, so Malibu Conform reads each value back after setting it. When a value ends up different from what was set (small differences are ignored), or could not be set or read, the clip gets a red marker named "Malibu Conform: Transform Check" and the report lists it.

The picture looks too small

If you conformed dailies proxies with burn-in bars, relink to the camera originals in Resolve; until then the proxies look too small. Also check the sizes on the Proxies tab.

Clips are offline after a manual import

Import again with Automatically import source clips into media pool enabled.

Cuts land on the wrong source frame

The preflight check warns about assets with Sony-style names that start at 0: Final Cut Pro may have failed to read the camera timecode, and cuts may land on the wrong source frame in Resolve. Relink the media in Final Cut Pro before you export.

The app asks for a license

When the license check blocks the app, for example after the trial, a screen offers Check Again, I already have a license, Lost your license key?, Buy Malibu Conform and Quit Malibu Conform; the device ID shown there is what support needs for a renewal. On the first launch a screen asks for your email address before you can continue. A key can be entered later under License in Settings with Redeem License Key....

Written for version 0.1.11.

Erste Schritte

Was Malibu Conform macht

Malibu Conform nimmt ein Final-Cut-Pro-Projekt, das du als FCPXML exportiert hast, und bereitet es für DaVinci Resolve Studio vor. Es schreibt eine Resolve-taugliche FCPXML, ein Manifest und einen Conform-Report. Optional importiert es die Timeline anschließend in Resolve und wendet dort die Transformationen an. Das Conform betrifft nur das Bild; Audio ist nicht Teil des Umfangs.

Bevor du startest

Du brauchst macOS 14.0 oder neuer und ein aus Final Cut Pro exportiertes Projekt.

Der automatische Resolve-Schritt braucht DaVinci Resolve Studio; die App warnt, dass die kostenlose Edition die Python-Scripting-API nicht enthält. Ohne Resolve bekommst du trotzdem die konformierten Dateien und kannst sie selbst importieren (siehe die Anleitung zum manuellen Import).

Der Resolve-Schritt läuft mit Python 3.10 oder 3.11. Die App nutzt ein in die App gebündeltes Python 3.11, wenn der Build eines enthält, und sucht sonst nach einem installierten 3.10 oder 3.11. Beim ersten Start kann die App nach deiner E-Mail-Adresse fragen, damit der Support deinen Testzugang finden und verlängern kann.

Aus Final Cut Pro exportieren

Wähle in Final Cut Pro das Projekt (die fertige Timeline, nicht ein Event oder die Mediathek) und exportiere es mit Ablage ▸ XML exportieren (englisch: File ▸ Export XML). Malibu Conform liest FCPXML-Versionen 1.10 bis 1.14, entweder als .fcpxml-Datei oder als .fcpxmld-Bundle. Eine Datei ohne Projekt-Timeline, etwa ein Event-Export, wird vom Preflight-Check blockiert oder als „nothing conformed“ gemeldet.

Die Datei conformen

Starte Malibu Conform und ziehe die Datei auf die Ablagefläche Drop FCPXML or .fcpxmld here, oder klicke auf die Fläche und wähle die Datei aus.

Lass die Optionen auf ihren Standardwerten und klicke auf Conform for Resolve.

Wenn der Preflight-Check etwas zu melden hat, auch nur Informationen, listet ein Fenster das zuerst auf. Klicke auf Conform Anyway, um fortzufahren; gibt es nur Informationen, heißt die Schaltfläche Conform. Ein Hard Block heißt, dass die Datei nicht konformiert werden kann; exportiere das Projekt neu und versuche es erneut.

Das Ergebnis lesen

Nach dem Lauf zeigt das Fenster die Dauer, eine Zusammenfassung (Clips, Multicams, eingebettete Compounds, Transformationen, entfernte Effekte), die Ausgabedateien und eventuelle Warnungen. Die Schaltflächen heißen Open Output Folder, View Report, Import into Resolve und New Conform.

Die Dateien liegen im Ausgabeordner, standardmäßig Movies/MalibuConform in deinem Benutzerordner: <Eingabename>_Conform.fcpxml, manifest.json, ConformReport.md und ConformReport.pdf, dazu ein Referenzfilm, falls du einen angegeben hast.

Was in Resolve passiert

Ist Drive Resolve after export eingeschaltet und Resolve Studio eingerichtet, startet Malibu Conform Resolve, falls es nicht läuft. Es importiert die FCPXML als Timeline, benannt nach deiner Datei mit dem Zusatz _Conform, in das Projekt, das in Resolve offen ist, wendet die Transformationen an und liest die Werte zur Kontrolle zurück. Clips mit mehreren Keyframes bleiben so, wie Resolve sie importiert hat, und bekommen nur einen Marker.

Ist die Option ausgeschaltet, öffnet sich stattdessen ein Fenster mit Import-Anleitung.

DaVinci Resolve einrichten

Die Einrichtung prüfen

Öffne die Einstellungen der App (das Zahnrad in der Kopfzeile), wähle den Tab Resolve und klicke auf Check Resolve Setup. Die Liste zeigt Installed, Studio Edition, Scripting Available und Python.

Beim allerersten Start öffnet sich ein Einrichtungsfenster. Klicke auf Check Setup, um die Prüfungen auszuführen; die Schaltfläche heißt danach Re-check. Skip schließt das Fenster und Done erscheint, sobald alles bereit ist. Die Liste dort ist anders beschriftet als die Liste in den Einstellungen, zum Beispiel „Studio edition detected“. Findet ein späterer Start etwas Fehlendes, bietet ein Hinweisbalken Check Setup an.

Die Studio-Edition verwenden

Der automatische Modus braucht DaVinci Resolve Studio; laut Hinweis der App enthält die kostenlose Edition die Python-Scripting-API nicht. Die Prüfung sucht Resolve und seine Scripting-Bibliothek am Standardort im Programme-Ordner; eine Kopie an anderer Stelle wird als nicht installiert gemeldet. Sie prüft auf diese Dateien, nicht auf eine Lizenz.

Externes Scripting aktivieren

Öffne in DaVinci Resolve die Einstellungen und setze External scripting using auf Local. Der Einrichtungshinweis der App nennt den Pfad Preferences → System → External Scripting Using → Local; die Meldung des Resolve-Schritts nennt Preferences > General. Ohne die Einstellung läuft Resolve eventuell, antwortet aber nicht, und der Resolve-Schritt bricht mit einem Hinweis ab, der dich auf diese Einstellung verweist.

Ein Projekt in Resolve öffnen

Malibu Conform importiert in das Projekt, das in Resolve gerade offen ist, und legt nie selbst eines an. Öffnet sich innerhalb von 20 Sekunden kein Projekt, bricht der Resolve-Schritt mit „No project is open in Resolve. Open (or create) a project, then run again.“ ab. Dateien und Report werden trotzdem geschrieben; der Fehler erscheint als Warnung „Resolve driver failed“.

Malibu Conform Resolve starten lassen

Läuft Resolve nicht, startet Malibu Conform es und wartet bis zu 180 Sekunden auf eine Antwort. Ein bereits laufendes Resolve, das nicht antwortet, wird nicht neu gestartet.

Den Resolve-Schritt ein- oder ausschalten

Verwende Drive Resolve after export, entweder in den Optionen des Hauptfensters (sichtbar, sobald eine Datei gewählt ist) oder in den Einstellungen unter Resolve. Die Option ist standardmäßig an. Schlägt die Einrichtungsprüfung beim App-Start fehl, steht das Häkchen im Hauptfenster für diese Sitzung zunächst auf aus, während die Einstellungen weiter deine gespeicherte Wahl zeigen.

Das Häkchen im Hauptfenster und das in den Einstellungen sind dieselbe Einstellung: Eine Änderung an einer der beiden Stellen gilt sofort und wird gespeichert.

Die konformierte Datei selbst in Resolve importieren

Wann du das brauchst

Importiere manuell, wenn Drive Resolve after export aus ist oder der Resolve-Schritt einen Fehler gemeldet hat. War die Option aus, öffnet sich die Anleitung nach dem Lauf von selbst; sonst klicke im Ergebnisfenster auf Import into Resolve.

Die Timeline importieren

Wähle in DaVinci Resolve Studio File → Import → Timeline… und nimm die Datei <Eingabename>_Conform.fcpxml, die das Fenster anzeigt. Show FCPXML in Finder zeigt sie im Finder.

Drei Importoptionen einschalten

Schalte im Importdialog Use color information, Mixed frame rate format: Final Cut Pro X und Automatically import source clips into media pool ein. Laut Anleitung der App sieht das Conform ohne diese drei Optionen im Inspector richtig aus, driftet aber im Bild; die Media-Pool-Option verknüpft die Clips mit deinen Medien.

Was ein manueller Import nicht enthält

Die roten Marker „Effect Removed“ und „Transform Check“, der gelbe Marker „Keyframed Transform“ und das Zurücklesen der Transformationswerte kommen aus dem Resolve-Schritt. Ein manueller Import hat nichts davon. Marker für Adjustment Layer und deine ursprünglichen Final-Cut-Pro-Marker stehen in der FCPXML und kommen in beiden Fällen an. Entfernte Filter stehen im Conform-Report und in manifest.json.

Conform-Report und Marker lesen

Den Report öffnen

Klicke im Ergebnisfenster auf View Report. Das öffnet ConformReport.pdf aus dem Ausgabeordner. Derselbe Report liegt dort auch als Markdown, ConformReport.md; View Report öffnet diese Datei, wenn sich das PDF nicht schreiben ließ.

Was der Report auflistet

Der Report hat eine Zusammenfassung und Abschnitte wie Critical — Manual Review Required, Warnings, Removed Effects, Multicam Resolutions, Transforms Applied, Source Media Rasters, Source Media, Cross-Clip Adjustment Layers, Custom LUTs Detected und Reference Movie. Am Ende stehen Hinweise für die Colorist:in.

Entfernte Effekte

Video-Filter auf Clips werden entfernt, auch Farbfilter, weil keiner nach Resolve übersetzt wird. Ein von einem Clip der Hauptstoryline entfernter Filter steht unter Removed Effects mit einem Vorschlag, wie du ihn in Resolve nachbaust. Ein von einem Connected Clip entfernter Filter erscheint stattdessen unter Warnings und bekommt keinen Marker in Resolve. Custom-LUT-Filter werden ebenfalls entfernt und zusätzlich unter Custom LUTs Detected aufgeführt.

Marker in Resolve

Marker auf Clips kommen aus zwei Quellen. Das Conform schreibt einen Marker „Adjustment Layer: <Name>“ auf den ersten Clip, den ein Adjustment Layer überdeckt. Die übrigen setzt der Resolve-Schritt. Ein roter Marker „Effect Removed“ mit dem Filternamen zeigt einen entfernten Filter. Ein roter Marker „Malibu Conform: Transform Check“ listet Transformationswerte, die nicht wie vorgesehen angekommen sind. Ein gelber Marker „Keyframed Transform“ heißt, der Clip hat mehr als einen Transform-Keyframe und blieb so, wie Resolve ihn importiert hat; prüfe die Animation gegen deine Referenz.

Warnungen im Ergebnisfenster

Das Ergebnisfenster zeigt die ersten zehn Warnungen in der Reihenfolge, in der sie entstanden sind; der Rest steht im Report. Der Report listet Fehler unter Critical — Manual Review Required und Warnungen unter Warnings; Informationen werden nur in der Zusammenfassung gezählt. Ein roter Punkt kennzeichnet einen Fehler, orange eine Warnung und grau eine Information.

Compound-Clips, Multicams und Sync-Clips behandeln

Was standardmäßig passiert

Im Normalfall werden Multicam-Clips durch ihren aktiven Winkel ersetzt und Sync-Clips auf ihren primären Videoclip entpackt, sodass Resolve normale Clips bekommt. Einige Fälle bleiben unverändert und bekommen eine Warnung, zum Beispiel ein retimter Wrapper mit Connected Video. Ein Compound-Clip wird aufgelöst, wenn er sich auf einen einzigen Clip reduziert. Ein Compound mit mehreren Clips bleibt ein Compound-Clip, und das Conform vermerkt die Information „Compound contains N elements — kept as compound“. Ein Compound, dessen einziger Inhalt ein Titel ist, wird nicht aufgelöst und mit „Inner element is not inlinable“ gemeldet.

Compounds mit mehreren Clips auflösen

Schalte vor Conform for Resolve in den Optionen Aggressive compound inlining ein, oder in den Einstellungen unter General. Malibu Conform nimmt dann den ersten inneren Clip eines solchen Compounds, wenn es ein Asset-Clip ist, und verwirft den Rest; ist das erste Element etwas anderes, bleibt das Compound unverändert. Verschachtelte Anordnungen können verloren gehen; nutze die Option nur, wenn die Compounds in deinem Schnitt reine Hüllen sind. Die Option ist standardmäßig aus.

Finden, was nicht konformiert wurde

Bleiben Clips mit Bild als Sync-, Compound- oder Multicam-Clip übrig, fügt das Conform eine Warnung mit der Anzahl hinzu: Sie landen in Resolve als Compound Clips, die sich nicht pro Clip graden lassen. Die Warnungen zu den einzelnen Clips nennen den Grund.

Connected Clips

Clips auf Lanes und in sekundären Storylines werden in der FCPXML konformiert, ihre Transformationen werden in Resolve aber nicht angewendet: Der Resolve-Schritt spricht nur Clips auf Videospur 1 an. Ein Hinweis in den Warnungen nennt, wie viele Connected Clips konformiert wurden.

Dailies-Proxies mit Burn-in-Balken konformieren

Wann du das brauchst

Nutze das, wenn dein Schnitt auf Dailies-Proxies mit zusätzlichen Burn-in-Zeilen entstand, die die Kameraoriginale nicht haben. Das Conform rechnet dann Clips, deren Quellraster zu einem von dir eingetragenen Proxy-Raster passt, für die Kameraoriginale; Clips mit anderen Rastern bleiben unverändert.

Ein Proxy-Raster hinzufügen

Öffne die Einstellungen, wähle den Tab Proxies und klicke auf Add Proxy Raster. Eine neue Zeile startet mit den Platzhaltergrößen 1920 × 1080 für den Proxy und 3840 × 2160 für das Original; ersetze beide durch deine Größen. Trage Proxy size und Original size ein. Die Balken werden aus den beiden Größen berechnet: Die Bildfläche ist der größte Teil des Proxys mit dem Seitenverhältnis des Originals, zentriert, und ein übrig bleibendes Pixel geht nach unten oder rechts. Eine Zeile mit geänderten Balken folgt den Größen nicht mehr.

Ungleiche Balken setzen

Ändere einen beliebigen Balken unter Bars (px) (Top, Bottom, Left, Right), um eigene Werte einzutragen. Die Zeile zeigt dann „Custom bars.“; mit Work out from sizes kehrst du zu den automatischen Werten zurück. Mit dem Papierkorb-Knopf entfernst du eine Zeile.

Das Conform ausführen

Die Zeilen werden bei jedem Conform-Lauf neu gelesen. Der Conform-Report listet die Rastergrößen deines Projekts unter Source Media Rasters. Relinke in Resolve auf die Kameraoriginale, bevor du das Bild prüfst; bis dahin wirken die Proxies zu klein.

Bekannte Grenzen

Clips mit Keyframes werden nicht auf das Kameraoriginal umgerechnet; das Conform warnt für jeden davon, und du prüfst Größe und Position nach dem Relink.

Referenz

Voraussetzungen und Versionen

  • macOS 14.0 oder neuer.
  • Eingabe: FCPXML-Versionen 1.10 bis 1.14 als .fcpxml-Datei oder .fcpxmld-Bundle, exportiert aus einem Final-Cut-Pro-Projekt.
  • Resolve-Schritt: DaVinci Resolve Studio mit externem Scripting auf Local und Python 3.11. Die App nutzt ein mit dem Build gebündeltes Python 3.11, wenn es eines gibt, und weicht sonst auf ein python.org-3.11, ein Homebrew-3.10 oder -3.11 oder /usr/bin/python3 aus, falls das 3.10 oder 3.11 ist.
  • Nur gegen DaVinci Resolve Studio 21.1.0.17 verifiziert; andere Resolve-Versionen sind ungetestet.

Hauptfenster

  • Drop FCPXML or .fcpxmld here — die Ablagefläche; ein Klick darauf öffnet stattdessen die Dateiauswahl.
  • Drive Resolve after export — Standard: an; das Häkchen im Hauptfenster startet für die Sitzung auf aus, wenn die Resolve-Einrichtungsprüfung beim App-Start fehlschlägt. Führt nach dem Schreiben der Dateien den Resolve-Schritt aus.
  • Aggressive compound inlining — Standard: aus. Löst Compounds mit mehreren Clips auf und behält nur den ersten.
  • Include reference movie — Standard: an. Übernimmt den unter Reference Movie gewählten Film in die Ausgabe.
  • Burn in timecode if missing — Standard: an. Legt den Start-Timecode der Timeline als Text über den Referenzfilm, sofern sein Dateiname nicht schon auf Timecode hindeutet.
  • Select... — wählt einen Referenzfilm. Change... — wählt den Ausgabeordner.
  • Conform for Resolve — startet den Preflight-Check und das Conform.

Die Optionen erscheinen, sobald eine Datei gewählt ist.

Einstellungen

  • General — Aggressive compound inlining (aus), Include reference movie (an), Burn in timecode if missing (an, nur wählbar, solange ein Referenzfilm einbezogen ist) und der Ausgabeordner mit Choose.... Der Standard-Ausgabeordner ist Movies/MalibuConform in deinem Benutzerordner.
  • Resolve — Drive Resolve after export (an), die Statusliste und Check Resolve Setup.
  • Proxies — Proxy-Raster mit Burn-in-Balken; siehe die Anleitung zu Proxies.
  • License — zeigt Status, E-Mail und Geräte-ID; Redeem License Key... und Deactivate This Device....
  • Diagnostics — Verbose logging (aus), Open Log Directory und Send Feedback….

Die Optionen im Hauptfenster und die passenden Optionen hier sind dieselben Einstellungen: Eine Änderung an einer der beiden Stellen gilt sofort und wird gespeichert. Der Tab Proxies wird bei jedem Lauf gelesen.

Menüs und Tastenkürzel

  • Malibu Conform ▸ Check for Updates… sucht nach einer neuen Version.
  • Help ▸ Send Feedback… öffnet das Feedback-Fenster; das Kürzel ist ⌘?.

Ausgabedateien

  • <Eingabename>_Conform.fcpxml — die Resolve-taugliche FCPXML. Sie behält die Version der Eingabe.
  • manifest.json — die Transformationen und entfernten Filter, die der Resolve-Schritt liest.
  • ConformReport.md — der Conform-Report als Markdown.
  • ConformReport.pdf — derselbe Report als A4-PDF. Lässt es sich nicht schreiben, vermerkt das Conform eine Information, und der Markdown-Report ist trotzdem da.
  • reference_<Dateiname> — eine Kopie des Referenzfilms; <Name>_TC.mp4, wenn Timecode eingebrannt wurde.

Referenzfilm

Ein Referenzfilm muss eine Videospur haben. Er wird geprüft, in den Ausgabeordner kopiert und im Report aufgeführt. Ob er schon Timecode eingebrannt hat, wird am Dateinamen erraten: Namen mit „_tc“, „timecode“ oder „burnin“ gelten als solche.

Schweregrade von Warnungen

Eine Meldung ist ein Hard Block, ein Fehler, eine Warnung oder eine Information. Ein Hard Block hält das Conform vor dem Start an. Vor dem Lauf erscheinen nur die Funde des Preflight-Checks; bei Fehlern oder Warnungen heißt die Weiter-Schaltfläche Conform Anyway, bei reinen Informationen Conform. Warnungen aus dem Conform und dem Resolve-Schritt erscheinen danach im Ergebnisfenster und im Report.

Grenzen

  • Nur Bild. Audio ist nicht Teil des Umfangs; Connected Audio eines aufgelösten Wrappers fällt weg.
  • Transformationen werden nur auf Clips der Videospur 1 angewendet. Connected Clips werden in der FCPXML konformiert, in Resolve aber nicht angefasst.
  • Video-Filter auf Clips werden entfernt und gemeldet; keiner wird nach Resolve übersetzt. Bei Connected Clips werden sie nur als Warnung gemeldet und bekommen keinen Marker in Resolve.
  • Clips mit mehr als einem Transform-Keyframe behalten, was Resolve importiert hat, und bekommen einen gelben Marker; der Resolve-Schritt kann keine Keyframes schreiben. Connected Clips mit Keyframes bekommen keinen Marker.
  • Adjustment Layer werden nicht auf die Clips angewendet, die sie überdecken. Ein Titel, der ein Adjustment Layer mit Transformation ist und auf der Hauptstoryline liegt, wird aus der Ausgabe entfernt, auf dem ersten überdeckten Clip markiert und im Report aufgeführt; Adjustment Layer an anderer Stelle werden nicht erkannt.
  • Bei Audition-Clips kommt nur die aktive Auswahl in Resolve an.
  • Pan- und Tilt-Einheiten sind nur für Resolves Skalierungsmodi Crop und Fit gemessen.
  • Die Studio-Prüfung testet auf eine Datei am Standardort von Resolve, nicht auf eine Lizenz.

Fehlersuche

Die Datei wird vor dem Conform abgelehnt

„This appears to be an Event XML (clip-only) export“: Du hast ein Event oder die Mediathek ohne Projekt exportiert. Wähle in Final Cut Pro das Projekt und exportiere es neu. „No timeline sequence found in FCPXML“ heißt, die Datei enthält gar kein Projekt und keine Timeline; exportiere das Projekt erneut. „FCPXML … is not supported. Need 1.10–1.14“: Die Datei hat eine andere FCPXML-Version; die Meldung nennt Final Cut Pro 10.6.5 oder neuer als Quelle.

Das Conform ist fertig, aber nichts hat sich geändert

Der Report meldet, dass keine Multicam- oder Compound-Clips in einer konformierbaren Projekt-Timeline lagen. Wahrscheinlich ist die Datei ein Export von Event oder Mediathek, oder das exportierte Projekt ist leer. Wähle in Final Cut Pro das Projekt und exportiere es neu.

Clips bleiben in Resolve Compound-Clips

Compounds mit mehreren Clips bleiben standardmäßig Compounds. Schalte Aggressive compound inlining ein, wenn du akzeptierst, dass nur der erste Clip bleibt. Siehe die Anleitung zu Compound-Clips.

Resolve antwortet nicht

„Cannot connect to Resolve. It is running, but scripting does not answer“: Setze in den Resolve-Einstellungen External scripting using auf Local und starte das Conform erneut. „It was started but did not answer within 180 s“: Warte, bis Resolve fertig gestartet ist, prüfe dieselbe Einstellung und versuche es erneut.

In Resolve ist kein Projekt offen

Öffne oder erstelle in Resolve ein Projekt und starte das Conform erneut. Malibu Conform legt nie selbst ein Projekt an.

Resolve kann die Datei nicht importieren

„Resolve failed to import the FCPXML“: Prüfe, dass alle Quellmedien erreichbar sind. Die FCPXML im Ausgabeordner lässt sich auch von Hand importieren; siehe die Anleitung zum manuellen Import.

Kein kompatibles Python gefunden

„No compatible Python 3.10 or 3.11 found“: Das mitgelieferte Python war nicht nutzbar, und es wurde kein installiertes 3.10 oder 3.11 gefunden. Installiere Python 3.11 von python.org oder mit Homebrew. Python 3.12 und neuer funktioniert nicht mit Resolves Scripting-Bibliothek.

Ein „Transform Check“-Marker erscheint

Resolve kann Werte stillschweigend beschneiden, deshalb liest Malibu Conform jeden Wert nach dem Setzen zurück. Weicht ein Wert vom gesetzten ab (kleine Abweichungen werden ignoriert) oder ließ er sich nicht setzen oder lesen, bekommt der Clip einen roten Marker „Malibu Conform: Transform Check“, und der Report listet ihn.

Das Bild wirkt zu klein

Hast du Dailies-Proxies mit Burn-in-Balken konformiert, relinke in Resolve auf die Kameraoriginale; bis dahin wirken die Proxies zu klein. Prüfe außerdem die Größen im Tab Proxies.

Clips sind nach einem manuellen Import offline

Importiere erneut, mit eingeschaltetem Automatically import source clips into media pool.

Schnitte landen auf dem falschen Quellbild

Der Preflight-Check warnt vor Assets mit Sony-typischen Namen, die bei 0 beginnen: Final Cut Pro hat eventuell den Kamera-Timecode nicht gelesen, und Schnitte können in Resolve auf dem falschen Quellbild landen. Relinke die Medien in Final Cut Pro, bevor du exportierst.

Die App fragt nach einer Lizenz

Blockiert die Lizenzprüfung die App, zum Beispiel nach der Testphase, bietet ein Bildschirm Check Again, I already have a license, Lost your license key?, Buy Malibu Conform und Quit Malibu Conform an; die dort gezeigte Geräte-ID braucht der Support für eine Verlängerung. Beim ersten Start fragt ein Bildschirm nach deiner E-Mail-Adresse, bevor du weitermachen kannst. Einen Schlüssel kannst du später in den Einstellungen unter License mit Redeem License Key... eingeben.
