What's inside

What the current version (1.29) actually does.

Measure

Real-time EBU R128 loudness

Momentary, short-term and integrated LUFS plus loudness range (LRA), live, in a standalone app that needs no DAW. Since 1.29 the LUFS read-outs are only computed while the LUFS meter is visible, which keeps CPU use down.

Native multichannel

5.0, 5.1 and 7.1 sources are measured natively, with results checked against EBU Tech 3341.

Tap any app's audio

Four capture backends: AVAudioEngine input, AUHAL device, ScreenCaptureKit and Process Tap. Process Tap compensates the mixdown attenuation automatically.

Peak, RMS, spectrum

Peak and RMS bars, a spectrum display and a Lissajous goniometer.

Five ballistics

Digital peak, PPM (EBU, DIN, Nordic) and VU.

Test-signal mode

Run the meter on a generated test signal instead of live audio.

Broadcast and streaming presets

EBU R128, Netflix, Apple TV+, YouTube, Spotify, Apple Music and ATSC A/85.

Your own status colours

Set the colours for too quiet, in range and too loud. Import and export settings and gradients.

Good to know

What you need, and what it does not do yet.

Requirements

  • macOS 14.0 or later
  • Trial first, then a license key unlocks the app

Not there yet

  • Settings export currently covers only part of the settings
  • The Process Tap fix has so far been verified on one macOS version only
