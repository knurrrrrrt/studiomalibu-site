What's inside

Everything a professional set needs.

MalibuSync thinks through the entire workflow — from TC matching to the finished audio channel structure at the edit suite.

⏱️

Timecode Matching

Reads TC directly from the MOV container (tmcd atom) and BWF files (bext chunk). Supports drop-frame, non-drop-frame, and all common frame rates. Offspeed and slow-motion clips are handled correctly.

👏

Clap as Fallback

When no timecode is available: adaptive transient detection finds the clap in the audio automatically. Works even with offspeed material that has unreliable TC.

🎚️

Automatic Channel Selection

MalibuSync analyzes all audio tracks and automatically selects the best channel per clip — Iso Mix, Boom, or Lav. The channel structure arrives in Final Cut Pro fully configured.

📋

ALE and CSV Import

Camera reports in ALE or CSV format are read and the metadata (Scene, Take, Reel, Notes) written directly into FCP metadata fields — no manual entry required.

📡

Lockit Network

On productions using the Lockit wireless system, MalibuSync pulls set metadata live via the Lockit Network REST API. Scene, Take, timecode status — directly from the set.

🎞️

Sync Clips + Multicam

When multiple cameras share timecode overlap, MalibuSync automatically creates multicam clips with separate angles — in addition to the individual synchronized clips.

What the FCPXML contains

  • Synchronized clips with video and all audio tracks
  • Multicam clips for multi-camera shoots (automatically grouped)
  • Scene / Take / Reel / Notes in FCP metadata fields
  • Audio channel roles (Lav, Boom, Iso Mix) correctly assigned
  • Active channel pre-selected — inactive channels switchable with one click
  • LUFS targeting and Voice Isolation as FCP Audio Adjustments
  • Sync and pickup markers on the clips
  • Non-destructive — not a single file is modified
