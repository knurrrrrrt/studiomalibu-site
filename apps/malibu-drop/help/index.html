Getting started

What Malibu Drop does

Malibu Drop is a menu bar app for Final Cut Pro. You drop a file on a tile; the file is copied (or moved) into the tile's media folder and imported into the tile's Final Cut event through a generated FCPXML.

Before you start

You need macOS 14 or later and Final Cut Pro with a library open. The target event must already exist in that library. PostLab is not required.

The seven default tiles accept audio only. Their media folders are placeholders that most Macs do not have. Before your first drop, set your own Media folder on each tile you use (see the tile setup guide); otherwise the drop fails because the folder's volume is not mounted.

Your first drop

Hold Shift while you drag a WAV file from Finder; the drop panel appears next to the cursor. Drop the file on the tile Songs. Or choose Import files to… in the menu bar menu and pick the tile; a file panel opens.

When the event exists in the library that is open in Final Cut, the clip appears in the event named in Final Cut event. The menu lists the result under Recent.

If it does not import at once

If Final Cut is not running or the event is missing, the drop waits and Malibu Drop tries again. See the guide on failed drops.

Set up a tile

Open the tile settings

Choose Settings… in the menu bar menu. The sidebar lists your tiles; select one to edit it.

Point the tile at a folder and an event

Under Destination, click Choose… to pick the Media folder, and type the Final Cut event exactly as it is named in the library. Use the Project field only to group tiles in the drop panel.

Set role, channels and level

Under Audio, set the Role; the menu next to it lists roles read from the open library. Channels (stereo files only) offers Unchanged, Stereo, Dual Mono, Mono and Swapped. Switch on Change level to apply a fixed level in dB to audio clips.

Allow video and stills

Under Files, Accept decides which kinds the tile takes. New and default tiles accept audio only. Switch on Video or Image there to take those too.

Add, duplicate, remove, share

Use Add tile, Duplicate tile and Remove tile in the settings window. Export Tiles… and Import Tiles… (under the More menu) save and load your set as a JSON file. Importing replaces all your tiles after you confirm with Replace.

Drop files and folders

Drag onto a tile

Drag files or folders from Finder, Mail or a browser onto a tile in the drop panel. The tiles are not in the menu bar menu. Folders are expanded; each file is checked against the tile's Accept setting.

Show the drop panel while dragging

Hold Shift while you drag. The panel appears next to the cursor. You can also keep it on screen: choose Show tiles in the menu, or press the shortcut set under Appearance.

Import without dragging

Choose Import files to… in the menu, pick a tile and select files or folders in the panel. They go through the same path as a drop.

Folder names become keywords

With Folder names as keywords on (the default), the folder names of a dropped folder are written as keywords on the imported clips.

Copy or move

Original file decides whether the original is copied or moved into the media folder. New tiles copy. A name clash never overwrites: the new file gets a number. The subfolders of a dropped folder are recreated below the media folder. In move mode, files inside a Final Cut library are refused; copying them is allowed.

When PostLab locks the event

What happens

Malibu Drop finds the libraries open in Final Cut with lsof, then looks in the library for an event folder named with a lock symbol, a space and the tile's event name, which is how PostLab marks a locked event. If no open library has that event writable, the clip goes into your own Sort event. If the Sort event is locked too, the drop waits. This is checked at drop time and on every retry.

The Sort event

The Sort event is named Sort plus your first name on this Mac. The app has no setting for it, and Import Tiles keeps this Mac's name. The menu reminds you which clips sit there and still belong in their real event; clear the reminder with Dismiss notices. That Final Cut creates a missing Sort event itself was not verified live.

Without PostLab

Without PostLab nothing is locked and clips go to the event named on the tile.

Handle failed and waiting drops

Waiting drops

A drop waits when Final Cut is not running, no library is open or the event does not exist yet. The menu shows how many wait and the reason of the first one. Malibu Drop retries with pauses of 2, 5, 15 and 60 seconds, then every 300 seconds, and the list survives a restart. A drop that waits for a library or an event keeps waiting. A hand-over that fails five times, an unreadable file or a deleted tile moves the item to Needs attention.

Needs attention

Items that gave up appear under Needs attention with the reason. Click Retry to try again at once, or Dismiss to remove the entry; the file itself stays where it is. A notification appears for failed drops and for clips that were imported but not placed (only in the installed app). The menu bar icon switches to a warning symbol while something needs a look, and returns to normal after you open the menu unless a failed item or a notice remains.

Clips not found in the event

After the hand-over, Malibu Drop checks for up to about 20 seconds whether the clip shows up in the event. If it does not, the menu warns and keeps the notice across restarts until you choose Dismiss notices. Malibu Drop does not import the clip again by itself, to avoid a double import.

Connect clips at the playhead

Switch it on

Select the tile and switch on Connect at playhead under Timeline. It is off by default.

Allow Accessibility

Malibu Drop selects the clip in the Final Cut browser and chooses Edit > Connect to Primary Storyline from the menu, so any key binding you set works. This needs the Accessibility permission for Malibu Drop in System Settings. Importing itself works without it.

Several clips

With more than one clip Malibu Drop asks once: Import Only or Connect at Playhead. Clear Ask before connecting several to skip the question. The clips are connected at the playhead. Where they land depends on Final Cut's setting for positioning the playhead after an edit: with it on they sit back to back and the menu says so; with it off they stack in lanes at the same position. Malibu Drop reads that setting through English labels only; in other Final Cut languages the menu shows no note.

Limits

The menu item is found by its English, German or French title. If the item is not found, is disabled or does not react, Malibu Drop falls back to the Q key, which only works with Final Cut's default binding. Whenever the fallback is used, the placement is reported as: sent to Final Cut, but not confirmed.

Reference

Menu bar menu

Import files to…, Show tiles or Hide tiles (with the shortcut shown), Icons only, Settings…, Check for Updates…, Malibu Drop Help (from version 0.2.6; opens this documentation in the browser), Quit Malibu Drop. Sections Needs attention and Recent appear when there is something to show.

Tile options and defaults

Defaults below are those of a new tile; the default tiles set some values themselves (Songs: Stereo, -9 dB; SoundFX: Dual Mono). Name, Icon, Project: labels and grouping. Media folder and Final Cut event: destination. Role: audio and video role, empty means Final Cut's default. Channels (stereo files only): Unchanged is the default. Level: off by default. Spatial conform: Default leaves Final Cut's setting. Accept: audio only by default. Original file: Copy by default. Connect at playhead: off. Ask before connecting several: on. Open in LogicSplitter: off. Folder names as keywords: on.

Default tiles

The default tiles (Songs, Composer, SoundFX, Score Layout, Atmos, ADR Layout and ADR Recorded) are a starting point. Their media folders are placeholders: set your own Media folder on each tile you use.

Shortcut and drop panel

Under Appearance (the gear in the settings sidebar) you set the shortcut that shows or hides the tiles; it needs Control, Option or Command. Icons only shrinks the tiles. Hold Shift while dragging to show the panel at the cursor; the trigger key is fixed.

Limits and requirements

macOS 14.0 or later. Final Cut Pro only, with a library open. Packages and Final Cut library files are not accepted. In move mode, files inside a Final Cut library are refused. Folders are read up to 100,000 entries. Clips are imported only through a generated FCPXML; nothing is written into the library package. Not sandboxed.

Troubleshooting

The drop waits: no library open

The menu shows: no library open in Final Cut. Open the library in Final Cut. The waiting drop is retried automatically; the pause between tries grows up to five minutes, and opening the library does not trigger an immediate check.

The drop waits: event not found

The menu shows: event not found in the open library. The name in Final Cut event must match the library name; emoji variation selectors are ignored, everything else must be exact. Fix the name in the tile settings or create the event.

The folder or volume is not available

The error says that the volume is not mounted. The default media folders are placeholders. Set your own Media folder on the tile, on a volume that is mounted.

A file is skipped

The menu shows skipped with a reason. Typical reasons are file type not allowed (switch the kind on under Accept) and a package or Final Cut library is not media.

The clip is imported but not connected

The menu line says not placed. Allow Accessibility for Malibu Drop, make sure Final Cut is running, and check that Edit > Connect to Primary Storyline exists in your Final Cut language. If the line says not confirmed, look at the timeline.

A tile settings file was kept aside

If tiles.json cannot be read, Malibu Drop shows a notice, renames the file to tiles.json.corrupt- followed by the time, and shows the default tiles. If the file cannot be renamed, the default tiles are shown without a notice and your next change overwrites the unreadable file.

Erste Schritte

Was Malibu Drop macht

Malibu Drop ist eine Menüleisten-App für Final Cut Pro. Du ziehst eine Datei auf eine Kachel; die Datei wird in den Medienordner der Kachel kopiert (oder verschoben) und über eine generierte FCPXML in das Event der Kachel importiert.

Bevor du anfängst

Du brauchst macOS 14 oder neuer und Final Cut Pro mit einer geöffneten Library. Das Ziel-Event muss in dieser Library bereits existieren. PostLab ist nicht erforderlich.

Die sieben Standard-Kacheln nehmen nur Audio an. Ihre Medienordner sind Platzhalter, die die meisten Macs nicht haben. Setze vor dem ersten Drop auf jeder Kachel, die du nutzt, deinen eigenen Media folder (siehe Anleitung zur Kachel-Einrichtung); sonst scheitert der Drop, weil das Volume des Ordners nicht eingehängt ist.

Dein erster Drop

Halte die Umschalttaste, während du eine WAV-Datei aus dem Finder ziehst; das Drop-Panel erscheint neben dem Cursor. Lege die Datei auf die Kachel Songs. Oder wähle Import files to… im Menüleisten-Menü und die Kachel; ein Dateidialog öffnet sich.

Existiert das Event in der in Final Cut geöffneten Library, erscheint der Clip in dem Event aus Final Cut event. Das Ergebnis steht im Menü unter Recent.

Wenn es nicht sofort importiert

Läuft Final Cut nicht oder fehlt das Event, wartet der Drop und Malibu Drop versucht es erneut. Siehe die Anleitung zu fehlgeschlagenen Drops.

Eine Kachel einrichten

Kachel-Einstellungen öffnen

Wähle Settings… im Menüleisten-Menü. Die Seitenleiste listet deine Kacheln; wähle eine zum Bearbeiten.

Kachel auf Ordner und Event legen

Klicke unter Destination auf Choose…, um den Media folder zu wählen, und tippe das Final Cut event genau so, wie es in der Library heißt. Das Feld Project gruppiert Kacheln nur im Drop-Panel.

Rolle, Kanäle und Pegel setzen

Setze unter Audio die Role; das Menü daneben listet Rollen aus der geöffneten Library. Channels (stereo files only) bietet Unchanged, Stereo, Dual Mono, Mono und Swapped. Mit Change level wird ein fester Pegel in dB auf Audio-Clips angewendet.

Video und Standbilder zulassen

Unter Files legt Accept fest, welche Arten die Kachel annimmt. Neue und Standard-Kacheln nehmen nur Audio an. Schalte dort Video oder Image ein, um auch diese anzunehmen.

Hinzufügen, duplizieren, entfernen, teilen

Nutze Add tile, Duplicate tile und Remove tile im Einstellungsfenster. Export Tiles… und Import Tiles… (im Menü More) speichern und laden dein Set als JSON-Datei. Beim Import werden alle Kacheln ersetzt, nachdem du mit Replace bestätigt hast.

Dateien und Ordner droppen

Auf eine Kachel ziehen

Ziehe Dateien oder Ordner aus Finder, Mail oder Browser auf eine Kachel im Drop-Panel. Die Kacheln sind nicht im Menüleisten-Menü. Ordner werden aufgelöst; jede Datei wird gegen die Einstellung Accept der Kachel geprüft.

Drop-Panel beim Ziehen zeigen

Halte beim Ziehen die Umschalttaste gedrückt. Das Panel erscheint neben dem Cursor. Du kannst es auch dauerhaft anzeigen: wähle Show tiles im Menü oder nutze das Kürzel aus Appearance.

Ohne Ziehen importieren

Wähle Import files to… im Menü, dann eine Kachel und Dateien oder Ordner im Dialog. Sie laufen über denselben Weg wie ein Drop.

Ordnernamen werden Keywords

Ist Folder names as keywords an (Standard), werden die Ordnernamen eines gedroppten Ordners als Keywords auf die importierten Clips geschrieben.

Kopieren oder verschieben

Original file legt fest, ob das Original in den Medienordner kopiert oder verschoben wird. Neue Kacheln kopieren. Ein Namenskonflikt überschreibt nie: die neue Datei bekommt eine Nummer. Die Unterordner eines gedroppten Ordners werden unter dem Medienordner nachgebaut. Im Verschieben-Modus werden Dateien innerhalb einer Final-Cut-Library abgelehnt; Kopieren ist erlaubt.

Wenn PostLab das Event sperrt

Was passiert

Malibu Drop findet mit lsof die in Final Cut geöffneten Libraries und sucht dann in der Library einen Event-Ordner, der aus einem Schloss-Symbol, einem Leerzeichen und dem Event-Namen der Kachel besteht; so markiert PostLab ein gesperrtes Event. Hat keine geöffnete Library dieses Event beschreibbar, landet der Clip in deinem eigenen Sort-Event. Ist auch das Sort-Event gesperrt, wartet der Drop. Das wird beim Drop und bei jedem erneuten Versuch geprüft.

Das Sort-Event

Das Sort-Event heißt Sort plus dein Vorname auf diesem Mac. Die App hat dafür keine Einstellung, und Import Tiles behält den Namen dieses Macs. Das Menü erinnert dich, welche Clips dort liegen und noch ins echte Event gehören; die Erinnerung löschst du mit Dismiss notices. Dass Final Cut ein fehlendes Sort-Event selbst anlegt, wurde nicht live verifiziert.

Ohne PostLab

Ohne PostLab ist nichts gesperrt und Clips gehen in das Event der Kachel.

Fehlgeschlagene und wartende Drops behandeln

Wartende Drops

Ein Drop wartet, wenn Final Cut nicht läuft, keine Library offen ist oder das Event noch nicht existiert. Das Menü zeigt, wie viele warten und den Grund des ersten. Malibu Drop versucht es mit Pausen von 2, 5, 15 und 60 Sekunden, danach alle 300 Sekunden erneut, und die Liste übersteht einen Neustart. Ein Drop, der auf Library oder Event wartet, wartet weiter. Eine Übergabe, die fünfmal scheitert, eine unlesbare Datei oder eine gelöschte Kachel verschiebt den Eintrag nach Needs attention.

Needs attention

Aufgegebene Einträge erscheinen unter Needs attention mit dem Grund. Retry versucht es sofort erneut, Dismiss entfernt den Eintrag; die Datei selbst bleibt, wo sie ist. Für fehlgeschlagene Drops und für importierte, aber nicht platzierte Clips erscheint eine Mitteilung (nur in der installierten App). Das Menüleisten-Symbol wechselt zu einem Warnsymbol, solange etwas Aufmerksamkeit braucht, und kehrt nach dem Öffnen des Menüs zurück, sofern kein fehlgeschlagener Eintrag oder Hinweis bleibt.

Clips nicht im Event gefunden

Nach der Übergabe prüft Malibu Drop bis zu etwa 20 Sekunden, ob der Clip im Event auftaucht. Falls nicht, warnt das Menü und behält den Hinweis über Neustarts hinweg, bis du Dismiss notices wählst. Malibu Drop importiert den Clip nicht selbst erneut, um einen Doppelimport zu vermeiden.

Clips am Playhead anhängen

Einschalten

Wähle die Kachel und schalte unter Timeline Connect at playhead ein. Standardmäßig ist es aus.

Bedienungshilfen erlauben

Malibu Drop wählt den Clip im Final-Cut-Browser aus und wählt im Menü Edit > Connect to Primary Storyline, deshalb funktioniert jede Tastenbelegung. Dafür braucht Malibu Drop die Bedienungshilfen-Berechtigung in den Systemeinstellungen. Der Import selbst funktioniert auch ohne.

Mehrere Clips

Bei mehr als einem Clip fragt Malibu Drop einmal: Import Only oder Connect at Playhead. Mit abgeschaltetem Ask before connecting several entfällt die Frage. Die Clips werden am Playhead angehängt. Wo sie landen, hängt von Final Cuts Einstellung zum Positionieren des Playheads nach einem Edit ab: eingeschaltet liegen sie hintereinander und das Menü weist darauf hin; ausgeschaltet stapeln sie sich in Spuren an derselben Position. Malibu Drop liest diese Einstellung nur über englische Beschriftungen; in anderen Final-Cut-Sprachen zeigt das Menü keinen Hinweis.

Grenzen

Der Menüpunkt wird über seinen englischen, deutschen oder französischen Titel gefunden. Wird der Menüpunkt nicht gefunden, ist er deaktiviert oder reagiert nicht, fällt Malibu Drop auf die Q-Taste zurück, die nur mit Final Cuts Standardbelegung funktioniert. Wird dieser Rückfall benutzt, meldet das Menü die Platzierung als: sent to Final Cut, but not confirmed.

Referenz

Menüleisten-Menü

Import files to…, Show tiles oder Hide tiles (mit angezeigtem Kürzel), Icons only, Settings…, Check for Updates…, Malibu Drop Help (ab Version 0.2.6; öffnet diese Dokumentation im Browser), Quit Malibu Drop. Die Bereiche Needs attention und Recent erscheinen, wenn es etwas zu zeigen gibt.

Kachel-Optionen und Standardwerte

Die Standardwerte unten gelten für eine neue Kachel; die Standard-Kacheln setzen einzelne Werte selbst (Songs: Stereo, -9 dB; SoundFX: Dual Mono). Name, Icon, Project: Bezeichnung und Gruppierung. Media folder und Final Cut event: Ziel. Role: Audio- und Video-Rolle, leer bedeutet Final Cuts Standard. Channels (stereo files only): Standard ist Unchanged. Level: standardmäßig aus. Spatial conform: Default lässt Final Cuts Einstellung. Accept: standardmäßig nur Audio. Original file: standardmäßig Copy. Connect at playhead: aus. Ask before connecting several: an. Open in LogicSplitter: aus. Folder names as keywords: an.

Standard-Kacheln

Die Standard-Kacheln (Songs, Composer, SoundFX, Score Layout, Atmos, ADR Layout und ADR Recorded) sind ein Ausgangspunkt. Ihre Medienordner sind Platzhalter: setze auf jeder Kachel, die du nutzt, deinen eigenen Media folder.

Kürzel und Drop-Panel

Unter Appearance (das Zahnrad in der Einstellungs-Seitenleiste) legst du das Kürzel fest, das die Kacheln zeigt oder verbirgt; es braucht Control, Option oder Command. Icons only verkleinert die Kacheln. Halte beim Ziehen die Umschalttaste, um das Panel am Cursor zu zeigen; die Taste ist fest.

Grenzen und Voraussetzungen

macOS 14.0 oder neuer. Nur Final Cut Pro, mit geöffneter Library. Pakete und Final-Cut-Library-Dateien werden nicht angenommen. Im Verschieben-Modus werden Dateien innerhalb einer Final-Cut-Library abgelehnt. Ordner werden bis 100.000 Einträge gelesen. Clips werden nur über eine generierte FCPXML importiert; nichts wird in das Library-Paket geschrieben. Nicht sandboxed.

Fehlerbehebung

Der Drop wartet: keine Library offen

Das Menü zeigt: no library open in Final Cut. Öffne die Library in Final Cut. Der wartende Drop wird automatisch erneut versucht; die Pause zwischen den Versuchen wächst bis auf fünf Minuten, und das Öffnen der Library löst keine sofortige Prüfung aus.

Der Drop wartet: Event nicht gefunden

Das Menü zeigt: event not found in the open library. Der Name in Final Cut event muss zum Library-Namen passen; Emoji-Variantenselektoren werden ignoriert, alles andere muss exakt stimmen. Korrigiere den Namen in den Kachel-Einstellungen oder lege das Event an.

Der Ordner oder das Volume ist nicht verfügbar

Der Fehler sagt, dass das Volume nicht eingehängt ist. Die Standard-Medienordner sind Platzhalter. Setze auf der Kachel deinen eigenen Media folder auf einem eingehängten Volume.

Eine Datei wird übersprungen

Das Menü zeigt skipped mit einem Grund. Typische Gründe sind file type not allowed (schalte die Art unter Accept ein) und a package or Final Cut library is not media.

Der Clip ist importiert, aber nicht angehängt

Die Menüzeile sagt not placed. Erlaube Bedienungshilfen für Malibu Drop, stelle sicher, dass Final Cut läuft, und prüfe, ob Edit > Connect to Primary Storyline in deiner Final-Cut-Sprache existiert. Sagt die Zeile not confirmed, schau in die Timeline.

Eine Kachel-Einstellungsdatei wurde beiseitegelegt

Lässt sich tiles.json nicht lesen, zeigt Malibu Drop einen Hinweis, benennt die Datei in tiles.json.corrupt- mit der Uhrzeit um und zeigt die Standard-Kacheln. Lässt sich die Datei nicht umbenennen, werden die Standard-Kacheln ohne Hinweis gezeigt und deine nächste Änderung überschreibt die unlesbare Datei.
