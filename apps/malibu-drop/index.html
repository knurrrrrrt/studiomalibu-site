Three steps

From a loose file to a clip in the right event.

01

Drag onto a tile

Drag a file or folder from Finder, Mail or a browser onto a tile in the menu bar, or onto the drop panel next to your cursor.

02

It lands in the right place

The file is moved or copied into the matching media folder and imported into the matching event, with role, level and channel layout, through one generated FCPXML per drop.

03

The queue handles the rest

If PostLab has locked the target event, the clip goes into a Sort event instead, so nobody waits. Failed items stay in the menu with Retry and Dismiss.

What's inside

What the current beta (0.2.5) actually does.

Import

One FCPXML per drop

Every drop produces a single generated FCPXML, validated against Final Cut's own DTD. Files are never overwritten, duplicates are numbered, and nothing is ever written into the Final Cut Pro library package.

PostLab-aware

If the target event is locked by PostLab, the clip goes straight into a per-machine Sort <Name> event. Locks are detected through lsof.

Seven tiles, all editable

Songs, Composer, SoundFX, Score Layout, Atmos, ADR Layout and ADR Recorded are there by default. Edit any tile, and export or import your set as JSON.

Drop panel at the cursor

Hold Shift while dragging, or pin the panel. A global shortcut opens it too.

Keyboard routes

Import files… from the keyboard, or Connect at playhead via the Edit menu.

Audio, video, stills

Accepts audio, video and still images (PNG, JPG, TIFF, HEIC) from Finder, Mail and browsers.

Persistent import queue

Retries with growing back-off. Failed items show up in the menu with Retry and Dismiss, plus a notification. An arrival check warns about files that are still copying.

Stays out of the way

Nothing polls, so it idles at about 0 % CPU. Stems can be opened in LogicSplitter.

Good to know

What you need, and what it does not do yet.

Requirements

  • macOS 14.0 or later
  • Final Cut Pro; built to work with PostLab
  • Accessibility permission
  • Not sandboxed: it needs lsof, access to /Volumes and Accessibility

Not there yet

  • This is a beta; no user has confirmed it in daily work yet
  • Final Cut Pro's Position playhead setting is read through English labels only
  • Mono summing by ear and Final Cut Pro creating the Sort event are not fully verified
  • The arrival check only warns; there is no Mac App Store release
