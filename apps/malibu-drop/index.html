Four steps

From a loose file to a clip in the right event.

01

Set up a tile

In Settings…, choose a Media folder and type the Final Cut event exactly as it is named in the library. The media folders of the seven default tiles are placeholders, so set your own first.

02

Drop or import

Hold Shift while you drag files or folders from Finder, Mail or a browser; the drop panel appears next to the cursor. Or choose Import files to… in the menu bar menu.

03

Copied or moved, then imported

The file goes into the media folder (Original file decides copy or move; new tiles copy) and is imported into the event through a generated FCPXML. The result is listed under Recent.

04

Waiting drops are kept

If Final Cut is not running, no library is open or the event is missing, the drop waits and is retried. Items that give up appear under Needs attention with Retry and Dismiss.

What's inside

What the current beta (0.2.6) actually does.

Import

Through a generated FCPXML

Clips are imported only through a generated FCPXML; nothing is written into the library package. A name clash never overwrites a file: the new one gets a number. The subfolders of a dropped folder are recreated below the media folder, and folders are read up to 100,000 entries.

Copy or move

Original file decides whether the original is copied or moved into the media folder. New tiles copy. In move mode, files inside a Final Cut library are refused; copying them is allowed.

Seven default tiles, all editable

Songs, Composer, SoundFX, Score Layout, Atmos, ADR Layout and ADR Recorded are a starting point. Add, duplicate or remove tiles, and save or load your set as a JSON file with Export Tiles… and Import Tiles…. Importing replaces all your tiles after you confirm with Replace.

Drop panel at the cursor

Hold Shift while dragging; the trigger key is fixed. Show tiles, or the shortcut set under Appearance, keeps the panel on screen. The shortcut needs Control, Option or Command.

Role, channels, level

Under Audio, set the Role (the menu lists roles read from the open library) and the Channels of stereo files: Unchanged, Stereo, Dual Mono, Mono or Swapped. Change level applies a fixed level in dB.

Audio, video, stills

New and default tiles accept audio only. Switch on Video or Image under Accept to take those too. A file of a kind the tile does not accept is skipped.

Waiting drops

A drop waits when Final Cut is not running, no library is open or the event does not exist yet. Malibu Drop retries after 2, 5, 15 and 60 seconds, then every 300 seconds, and the list survives a restart.

Events locked by PostLab

An event PostLab has locked is recognized by the lock symbol in its folder name. The clip then goes into your Sort event (Sort plus your first name), and the menu reminds you which clips belong in their real event. If that is locked too, the drop waits. Without PostLab, clips go to the tile's event.

Needs attention

Items that gave up show the reason, with Retry and Dismiss; the file stays where it is. The menu bar icon shows a warning symbol while something needs a look.

Connect at playhead

Optional per tile, off by default. Malibu Drop chooses Edit > Connect to Primary Storyline in Final Cut, which needs the Accessibility permission. Importing works without it.

Folder names as keywords

On by default: the folder names of a dropped folder are written as keywords on the imported clips.

Good to know

What you need, what it does not do, and what to watch for.

Requirements

  • macOS 14.0 or later
  • Final Cut Pro with a library open; the target event must already exist in it
  • PostLab is not required
  • Accessibility permission, only for Connect at playhead
  • Malibu Drop is not sandboxed

What it does not do

  • Final Cut Pro only. Packages and Final Cut library files are not accepted as media.
  • It does not create the event or open the library for you; the drop waits until both exist.
  • It does not import a clip again by itself when the clip is not found in the event, to avoid a double import.
  • It reads Final Cut's setting for positioning the playhead after an edit through English labels only; in other Final Cut languages the menu shows no note.

Worth knowing

  • The default media folders are placeholders. Without your own Media folder on the tile, the drop fails because the volume is not mounted.
  • The name in Final Cut event must match the event in the library exactly; only emoji variation selectors are ignored.
  • Opening the library does not trigger an immediate retry; the pause between tries grows up to five minutes.
  • After the handover, Malibu Drop checks for about 20 seconds whether the clip shows up in the event. If not, the menu warns until you choose Dismiss notices.
  • If Edit > Connect to Primary Storyline is not found, is disabled or does not react, the Q key is used, which only works with Final Cut's default binding. The placement is then reported as sent to Final Cut, but not confirmed.
  • Whether Final Cut creates a missing Sort event by itself has not been verified live.
  • If tiles.json cannot be read, it is renamed to tiles.json.corrupt- followed by the time and the default tiles are shown.
