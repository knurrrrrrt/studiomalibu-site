Three steps

From a loose file to a clip in the right event.

01

Drag onto a tile

Drag a file or folder from Finder onto a tile in the menu bar, or onto the drop panel next to your cursor.

02

It lands in the right place

The file is moved or copied into the matching media folder and imported into the matching event, with role and channel layout, and level where the tile has a dB value, through one generated FCPXML per drop.

03

The queue handles the rest

If PostLab has locked the target event, the clip goes into a Sort event instead, so nobody waits. Failed items stay in the menu with Retry and Dismiss, and the queue survives a restart.

What's inside

What the current beta (0.2.5) actually does.

Import

One FCPXML per drop

Every drop produces a single generated FCPXML, validated against Final Cut's own DTD. Files are never overwritten, duplicates are numbered, and nothing is ever written into the Final Cut Pro library package. Folders become keywords.

PostLab-aware

If the target event is locked by PostLab, the clip goes straight into a per-machine Sort <Name> event. PostLab is optional; without it everything runs the same. Lock detection through lsof only matters with PostLab.

Seven tiles, all editable

Songs, Composer, SoundFX, Score Layout, Atmos, ADR Layout and ADR Recorded are there by default. Edit any tile, including level, mono and multichannel options, and export or import your set as JSON.

Drop panel at the cursor

Hold Shift while dragging to bring it up; the Shift trigger is fixed and not configurable. A global hotkey pins or unpins the panel.

Keyboard routes

Import files… from the keyboard. The optional Connect at playhead uses Edit > Connect to Primary Storyline in Final Cut Pro (English, German or French menus), otherwise only the Q key.

Audio, video, stills

The seven default tiles accept audio only. Video and still images (tested: PNG, JPG, TIFF) are accepted where a tile allows them, set per tile.

Persistent import queue

Retries with growing back-off. Failed items show up in the menu with Retry and Dismiss, plus a notification, and the menu-bar icon changes when something needs attention. After handing over to Final Cut Pro, an arrival check looks for the clip in the event database (up to 20 times, once a second) and warns “not confirmed” if it does not appear. It only warns; nothing is requeued.

Stems in LogicSplitter

“Open in LogicSplitter” appears only if LogicSplitter.app is installed; there is no way back into Final Cut Pro.

Good to know

What you need, and what it does not do yet.

Requirements

  • macOS 14.0 or later
  • Final Cut Pro; PostLab is optional
  • Accessibility permission, only for the optional Connect at playhead
  • Not sandboxed: it needs lsof (only relevant with PostLab) and access to /Volumes

Not there yet

  • This is a beta; no user has confirmed it in daily work yet
  • Final Cut Pro's Position playhead setting is read through English labels only
  • Mono summing by ear and Final Cut Pro creating the Sort event are not fully verified
  • The arrival check only warns that a clip is not confirmed; it does not requeue. There is no Mac App Store release
  • Drops from Mail and browsers (file promises): the code exists, but it is not confirmed live
  • Final Cut Pro only, and only with the library open (if Final Cut Pro is closed, the drop waits); no stems back into Final Cut Pro; packages and .fcpbundle are rejected
