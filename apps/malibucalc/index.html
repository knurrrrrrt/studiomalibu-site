The Workflow

Type, see, reuse.

🧮

Type a line

Write a calculation like any note — "Day rate * 12 days" — the result appears automatically on the right.

🏷️

Label it

Give a line a name — "Rent", "Crew total" — so the notepad reads like a real budget, not a spreadsheet.

🔗

Link values

Reference an earlier line by its label and build up totals without retyping numbers.

📝

Reuse the sheet

Keep the notepad around for the next production — swap the numbers, the structure stays.
