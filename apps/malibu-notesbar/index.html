A formatting bar for Notes.
Plus slash commands.

Malibu NotesBar adds a floating formatting toolbar and Notion-style slash commands directly inside Apple Notes — two things the app has never had. Select text and the bar appears automatically right at your selection; type a forward slash and a command menu opens.

The Workflow

Select, format, slash.

🔐

Grant Accessibility once

During onboarding, you grant Malibu NotesBar Accessibility permission once — that's what lets it see your text selection inside Apple Notes.

🖊️

Select text in Notes

Highlight any text in a note and a floating formatting bar appears automatically right at your selection.

✅

Click to format

Bold, italic, headings, lists, checklists — one click applies it, no menu diving, no keyboard-only shortcuts to memorize.

⚡

Type / for commands

Type a forward slash to bring up a Notion-style command menu — headings, lists, a fenced code block, dividers, and more.

What's inside

The formatting bar and slash commands Apple Notes never had.

One-click buttons right at your selection, and a slash command menu when you'd rather type — both live inside Apple Notes itself.

🗒️

Floating formatting bar

Select text inside Apple Notes and a formatting bar appears automatically, right where you're working — no hunting through menus.

🅱️

One-click formatting

Bold, italic, underline, strikethrough, monospaced, heading, and link — plus increase/decrease indent, text size, and remove formatting, all one click away.

📋

A full list toolkit

Bullet lists, dashed lists, numbered lists, and checklists — every list type Apple Notes' own toolbar leaves out.

⚡

Slash commands

Type / to open a Notion-style command menu: Heading 1–3, bullet and numbered lists, checklist, a fenced code block, and a divider.

🧩

Table, template & AI-assist

The slash menu also includes entries for a table, a template, and AI-assist — right alongside the formatting commands.

🍎

Built for Apple Notes

Malibu NotesBar's default and primary scope is Apple Notes — built to make Notes itself better, not to replace it with something heavier.
